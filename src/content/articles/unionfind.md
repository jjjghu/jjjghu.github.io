## 介紹

並查集，用來解決幾個集合彼此合併的東西。\
基本操作有以下幾個：

1. `int find(a)`：找到 $a$ 在哪個集合，當元素在相同集合時，會查出一樣的結果。
2. `bool isSame(a, b)`：判斷 $a$ 與 $b$ 是否在相同集合。

- $\{a,b,d\}$，此時 $a,b$ 在同一集合當中。
- $\{a,d\},\{b,x\}$ ，這時 $a,b$ 在不同集合當中。

3. `void union(a, b)`：將 $a$ 屬於的集合跟 $b$ 屬於的集合合併。

- 如果 $a\in{a,c,d}\\b\in{b,e,f}$ ，合併之後成為 $\{a,b,c,d,e,f\}$。
  要求以上操作均攤下來 $O(1)$ 的複雜度，這就是並查集。

---

一開始的集合只有 $\{a\}, \{b\}, \{c\}, \{d\}, \{e\}, \{f\}$ 這六個。

- 最初find函數都會找到自己。
  - $
    a\to{a},~b\to{b},~c\to{c},\\
    d\to{d},~e\to{e},~f\to{f}
    $
- 呼叫 `union(a, b)`，將兩個集合合併，隨便誰連到誰身上
  - $a\to{b}\to{b}$ ，其他相同，此時代表集合的是 $b$ 的編號。
  - 此時 `isSame(a, b)`，兩者在同個集合，都會找到 $b$ 的編號。
- 呼叫 `union(c, d)` 之後 `union(b, c)`。
  - `union(c, d)`： $c\to{d}\to{d}$
  - `union(b, c)`： $\blue{a\to{b}\to}{c}\to{d}\to{d}$
  - 在合併前，先判斷是否在相同集合，如果不是再去合併。
- 呼叫 `union(e, f)` 之後 `union(a, e)`。
  - `union(e, f)`： $e\to{f}\to{f}$
  - `union(a, e)`：先判斷兩邊的大小，將集合大小比較小的去接上大的， $\blue{a\to{b}\to{c}\to{d}\to}{e}\to{f}\to{f}$
    為了要滿足上述操作時，找到自己和小接大的操作，需要兩個陣列`father`和`size`。\
    假設最初集合是 $\{0\},\{1\},\{2\},\{3\},\{4\},\{5\}$ 。\
    `father = [0, 1, 2, 3, 4, 5]`，因為自己會指向自己。\
    `size = [1, 1, 1, 1, 1, 1]`，各自集合大小為一。
- `union(0, 1)`之後
  - `father = [1, 1, 2, 3, 4, 5]`
  - `size = [1, 2, 1, 1, 1, 1]`
  - 合併之後想要獲得大小時，先找到「代表該集合的點」（或是你可以叫它根節點），再去取`size`，因此根節點以外的元素的 `size` 就沒用了。
- `union(2, 3)`之後
  - `father = [1, 1, 3, 3, 4, 5]`
  - `size = [1, 2, 1, 2, 1, 1]`
  - 先找到各自的根節點，判斷各自集合大小之後合併。
- `union(4, 5)，union(3, 5)`
  - `father = [1, 1, 3, 3, 5, 5]` $\to$ `[1, 1, 3, 5, 5, 5]`
  - `size = [1, 2, 1, 2, 1, 2]` $\to$ `[1, 2, 1, 2, 1, 4]`
  - 先找到各自的根節點，判斷各自集合大小之後合併，小的合併到大的。
- `union(0, 5)`
  - `father = [1, 5, 3, 5, 5, 5]`
  - `size = [1, 2, 1, 2, 1, 6]`\
    之所以小掛大，是因為普遍來說，小掛大能產生的路徑長度會比較短。

---

第二個優化叫扁平化。\
在結束之後 `find(2)`，會一路往後找： $2\to3\to5\to5$ 。\
扁平化的意思就是，在找的過程中，順帶把中途路徑修改，連到根結點上。\
假設現在 `find(3)` 找的過程是 $3\to7\to2\to6\to8\to9\to100\to100$ ，\
那麼在找之後要改成：

$
3\to100\\
7\to100\\
2\to100\\
6\to100\\
8\to100\\
9\to100\\
100\to100
$

因為有用的資訊只有根結點，因此將節點都連到根結點，提高後續 `find()` 的速度。\
具體實現使用棧，當然也可以用隊列，隨便你怎麼用。\
兩個優化當中，扁平化是一定要做的，能大幅提高效率。\
至於為什麼複雜度這麼低，你不需要知道怎麼證明。\
發明並查集的兩人自己都證明了二十五年，有閒情逸致再自己上網找找。
