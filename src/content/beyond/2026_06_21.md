我很慶幸自己有留下這些記錄，過了一個月回頭看，還能穩妥地接續寫下去。自上次將角色們的天賦全數完成後，程式碼行數接近兩千，開始有了「屎山代碼」的跡象，於是想做一些重構。說是這樣說，也知道哪些腳本要處理，具體到底怎麼改反倒沒什麼頭緒，又沒有接觸過比較大的專案，於是出動每個月花費 663 元的 Claude Code 擬了一份修改清單。（原先想用新出的 fable 5 模型，結果它太強直接被禁用了）。這些紀錄本身也經過整理。重構後的程式碼十分優雅，又不會過度設計（至少目前來說）。

主要花時間在後續的「祝福」上。所謂祝福，是指角色受到強化過後的天賦，分成兩種，一種是單純的數值提高，比如「赤面手榴彈王」：初次碰撞敵方的攻擊力從兩倍變成三倍；另一種則是新增全新機制，比如「仰臥起坐」：受到攻擊後有 50% 的機率不會死掉並回復生命值。光聽描述，自然是後者比較難實現。以「仰臥起坐」為例，你會將祝福判斷安插在以下流程中的哪一段？

1.敵方拉動角色攻擊，它的 CharacterActionController 腳本建立一個 DamageInfo 物件，讓 DamageResolver 處理。
2. DamageResolver 接收到傷害相關資訊，對受害者觸發 ApplyDamage() 函數，這個函數會發出「生命值變動事件」。
3. DamageResolver 讓攻擊者觸發「傷害事件」，進而通知 UI 顯示傷害、並跳出傷害數字。
4. 判斷受害者是否死亡，如果有，讓受害者觸發「死亡事件」、攻擊者觸發「擊殺事件」，攻擊方分數 + 1。
※ 死亡的判定是角色當下生命值是否 <= 0。
※ 任何事件觸發時，角色天賦會收到此次事件相關資訊，並觸發對應的函數去處理。

直觀的想法是在「死亡事件」時觸發仰臥起坐。但死亡後，GameManager 會紀錄此次死亡的角色，在此輪行動結束後將死亡的角色重新召回場上。如果想寫在「死亡事件」中，就得在判斷角色死亡後，觸發死亡事件，然後再判斷一次角色是否死亡（因為仰臥起坐可能在死亡事件時觸發，讓角色現在沒死），最後根據二次判定的結果，觸發後續的擊殺與分數計算，但這方法很怪又很蠢。

也就是說，第四步前就需要將祝福觸發完畢，以規避上述問題。所以要在「生命值變動事件」中做手腳。天賦中判斷角色是否死亡（characterStats.isDead），假如死了便試著觸發仰臥起坐，成功的話便讓角色回復（characterStats.Heal），需要注意在回復之後，生命值會再次變動而觸發天賦，在這個例子中不會出現額外影響，不需理會。

問題出現的頻率比我想像中少，但也不少。像是水彈是被創建的物件，傷害數值原先由水彈自行管理，但「砰砰」的天賦是讓水彈攻擊由 4 提升到 10，所以傷害數值就得改由角色管理，最後讓子彈在發射的瞬間，才由角色的天賦狀態決定傷害，這個方式比 Claude 建議的方法還要好，讓我很自豪。

越寫越覺得，《豹豹碰碰大作戰》是個很適合給新手練習的項目，角色的天賦實作過程中，簡單的很簡單，難的特別麻煩，當中最麻煩的莫過於額外行動：「大力可以讓泡泡獲取額外行動，泡泡擊殺敵人也可以獲取一個，如果最後停留在『再動場』又可以獲取額外行動。」並且相同的額外行動來源不能連續觸發。

第一個問題：若泡泡既擊殺敵人又停留在再動場？它先觸發的是天賦還是再動場？第二個問題：大力讓泡泡獲取額外行動，而自己最後停留在再動場，是先觸發誰的額外回合？最後，現在的程式碼作法當中，持有額外行動的角色最多一位，怎麼改成能處理多角色再動的進階版本？

祝福之後還有技能，輪末當中會跳出來讓玩家三選一，其中有「先手優勢：下一輪中，首個行動的角色獲得額外行動。」

在 6/14 ~ 6/16 之間，跟國高中同學遊玩了《Escape the Backrooms》，大小 25.8 GB，比預想中大得多。第一關看起來像粗製濫造的遊戲，有了相對負面的開場。這一關中遊蕩的怪物聲音很吵，還卡在牆壁中動彈不得，三人對它取笑一番後，踏入了通往下一關的門。

第二關在一座地下停車場中，地上有好幾處水窪，滴水的聲音迴盪在昏暗的地底空間，讓我不太敢走太快。踩踏過水窪、走過兩個停車場的柱子後，看到了一扇白門，三人進到裡面，隨手關門，在桌面跟櫃子中找到了手電筒與杏仁水──用來照亮視野、與補充精神力的道具。見目前什麼都沒發生，三人出了門就自然地分頭行動，不出幾分鐘，▀▄█說自己被怪抓到了，出於害怕，我下意識走來時的路，看見柱子邊倒臥在地的屍體。

另一人料沉虛說自己在遠處看見了早已死亡的▀▄█，躲在撿到手電筒的房間內，那「人」似乎注意到了他的視線，來到門邊說道"excuse me?"，見裡頭的人沒反應，門也打不開，很快便走遠了。

另一邊，我看到扮演成料沉虛的人往我走過來，立刻往剛才白門的房間跑，跟他一同躲在桌子底下，外頭的人現出原形，發出精神汙染的噪音，徘徊許久，見他進不來，我們的膽子又大了起來，不斷開關門引誘他，最後在地下停車場追逐一整圈後團滅。

從這關開始，遊戲就變得好玩起來了。

遊戲的場景豐富，而每一關開頭附近都會放一張紙條，告訴玩家這關要做什麼，除此之外的提示不多，不過基本上一看就懂，不需要攻略，另外還有一些「機制」可以利用，除了跑跳比較快之外，還有「重置關卡可以刷取無限物資」能進一步降低難度。

總而言之，這遊戲非常適合多人同樂，玩到現在 11 個小時，還沒有全數通關。
