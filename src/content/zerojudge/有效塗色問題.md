## 思路

給定`n`、`m`兩個參數，代表一共`n`個格子，`m`種顏色。
當塗滿所有格子，且`m`種顏色都有被使用，這叫一種有效方法。
求一共有多少有效的塗色方法，答案可能很大，％1e9+7 後返回。 $1\leq n, m\leq 5000$

---

定義`dp[i][j]`代表在前面的n個格子中使用m種顏色塗色的合法方案數。

- `dp[i][j]`
  - `dp[i-1][j-1]`對應的方案，在尾端格子使用新的顏色。
    - `dp[i-1][j-1] × (m-j+1)`，最後一格必須選擇新顏色，來滿足`m`種顏色的要求。\
      比如前面有 r, g, b 三種顏色，後面要加入新的顏色x, rgb 能在前面 3 格對應的方案，都能在方案後填入新顏色`x`。\
      一共有`m`個顏色，因此新顏色`x`能從這`m`當中，減去已經用掉的`j-1`，一共`m-(j-1)`種選擇。
  - `dp[i-1][j]`對應的方案，在尾端加入與最後一個顏色不同的顏色。
    - 一共`dp[i-1][j] × j`\
      在前面的`i-1`格已經用了`j`種顏色，那這一個格子也有`j`種顏色可以選。

## 程式碼

```cpp
#include <iostream>
#include <vector>
#include <random>
using namespace std;
const int MOD = 1e9+7;
const int MX = 5001;
int dp[MX][MX]{}; // DP

int bruteForce(int n, int m) {
    vector<bool> used(m + 1, false);

    auto dfs = [&](this auto&&dfs, int idx) -> int {
        if(idx == n) {
            for(int i = 1; i <= m; i++) {
                if(!used[i]) {
                    return 0;
                }
            }
            return 1;
        }
        int res = 0;
        for(int j = 1; j <= m; j++) {
            bool old = used[j];
            used[j] = true;
            res += dfs(idx + 1);
            used[j] = old;
        }
        return res;
    };

    return dfs(0);
}

int DP(int n, int m) {
    for(int i = 1; i <= n; i++) {
        dp[i][1] = m; // 在 n 個格子中使用 1 種顏色的方案數有 m 種 (可選顏色一共 m 個)
    }

    for(int i = 2; i <= n; i++) {
        for(int j = 2; j <= m; j++) {
            dp[i][j] = (1LL * dp[i - 1][j] * j) % MOD;
            dp[i][j] = (1LL * dp[i - 1][j - 1] * (m - j + 1) + dp[i][j]) % MOD;
        }
    }
    return dp[n][m];
}

int main(void) {

    random_device rd;
    mt19937 gen(rd());
    uniform_int_distribution<int> distrib(1, 9); // 亂數產生的範圍, 1 ~ 9

    int testCase = 10;
    for(int t = 1; t <= testCase; t++) {
        int n = distrib(gen);
        int m = distrib(gen);
        printf("testCases \t%d: n = %d,\t m = %d, ", t, n, m);
        if(n < m) swap(n, m);
        int ans1 = DP(n, m);
        int ans2 = bruteForce(n, m);
        if(ans1 == ans2) {
            printf("answer = %d\t, passed!\n", ans1);
        }
        else {
            printf("ans1 = %d, ans2 = %d\t, wrong answer!\n", ans1, ans2);
        }
    }
}
```

> 狀態壓縮就不寫了，用到的格子是自己上面跟左上，跟路線圖前面的題目大同小異。

## 複雜度分析

- 時間複雜度：$O(mn)$
- 空間複雜度：空間壓縮前 $O(mn)$，空間壓縮後 $O(m)$
