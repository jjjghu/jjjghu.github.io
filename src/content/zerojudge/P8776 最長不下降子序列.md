## 思路

使用這個修改機會，肯定只會帶來好處而不會有壞處，所以肯定要用。

假如不使用時，最佳的答案是 $[a_1,\cdots,a_2,\cdots,a_3,\cdots,a_4]$ ，我使用這個修改機會的時候，可以用在任意兩個數字之間的空間，盡量選大的，這樣就能得到最多的好處，至於數值就設定為靠右的即可。比如在 $[a_3,\cdots,a_4]$ 之間加入 $k$ 個數值。這 $k$ 個數值就設定為 $a_4$ （當然你要設定為 $a_3$ 也可以）

這 $k$ 個數值放在 $[a_3,\cdots,a_4]$ 兩個數字之間，它的位置重要嗎？它不重要，因此我們能刻意將它放置在 $a_4$ 左邊，強制把 $a_4$ 左邊 $k$ 個數字修改成 $a_4$ 。

我們可以枚舉修改的那 $k$ 個位置（使用像滑動窗口的方式），並在左右兩邊各自求不下降子序列。滑出窗口的數字用來更新`ends`數組。

## 程式碼

### 動態規劃 + 二分搜

```cpp
#include <iostream>
#include <climits>
#include <algorithm>

using std::cin;
using std::cout;
using std::max;

const int MX = 1e5+1;
int nums[MX];
int right[MX]; // 以 nums[i] 為起點, nums[i...] 最長不下降子序列長度
int ends[MX]; // 長度為 i + 1 的最長不下降子數組的最小結尾

int findPos(int x, int endSize) {
    // ends 在這裡代表長度為 i + 1 的最長「不上升子數組」的「最大結尾」
    int pos = -1;
    int left = 0, right = endSize - 1;
    while(left <= right) {
        int mid = left + (right - left) / 2;
        if(ends[mid] < x) {
            pos = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    return pos;
}

int findPos2(int x, int endSize) {
    int pos = -1;
    int left = 0, right = endSize - 1;
    while(left <= right) {
        int mid = left + (right - left) / 2;
        if(ends[mid] > x) {
            pos = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    return pos;
}

// 正著看的最長不下降子數組
// 相當於倒過來計算最長不上升子數組
// 從 nums[n-1...j]看過來的，以 nums[j] 為結尾的最長不上升子序列。
// 相當於 nums[j...n-1], 以 nums[j] 為起點的最長不下降子序列。
void init(int n) {
    int endSize = 0;
    for(int i = n - 1; i >= 0; i--) {
        int pos = findPos(nums[i], endSize);
        if(pos == -1) {
            ends[endSize++] = nums[i];
            right[i] = endSize;
        } else {
            ends[pos] = nums[i];
            right[i] = pos + 1;
        }
    }
}

int main(void) {
    int n, k;
    cin >> n >> k;
    for(int i = 0; i < n; i++) {
        cin >> nums[i];
    }

    init(n); // 計算 right 數組

    int endSize = 0;
    int res = 0;
    for(int i = 0, j = k; j < n; i++, j++) {

        // 用 nums[j] 去找 ends 數組，得知用 <= nums[j] 的數字結尾的最長不下降子序列長度 left。
        int pos = findPos2(nums[j], endSize);
        int left = pos == -1 ? endSize : pos;
        res = max(res, left + k + right[j]);

        // 更新 ends 數組
        pos = findPos2(nums[i], endSize);
        if(pos == -1) {
            ends[endSize++] = nums[i];
        } else {
            ends[pos] = nums[i];
        }
    }
    res = max(res, endSize + k); // 最後 k 個數字變化，沒有右側。
    cout << res;
}
```

## 複雜度分析

- 時間複雜度：$O(n\log{n})$
- 空間複雜度：$O(n)$
