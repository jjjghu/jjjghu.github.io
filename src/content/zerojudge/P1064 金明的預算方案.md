## 思路

商品分為主件跟附件，假如你想要購買附件，那麼你得先購買主件，才能接著購買附件。每個主件最多有兩個附件，且附件不會有自己的附件。購買主件後，附件不一定要買，並不是綑綁銷售的。\
一個商品有分價格跟重要度以及歸屬，一個商品的收益 = 價格 $\times$ 重要度。

對於那些有附加商品的主要商品來說，它有更多購買的可能性。比如商品 4，如果你選它，一共有四種買法： $[4]$ ， $[4,1]$ ， $[4,5]$ ， $[4,1,5]$ ，在過程中，1, 5 這兩個附加商品的所有可能性已經被包含進去了。

---

- 建立一個陣列`king`，標記是不是主要商品。
- `fans`紀錄一個商品一共有多少附件。
- `follows`紀錄具體附屬的編號。

有了這些資訊後，就能方便展開這個商品的購買可能。

<p style="text-align:center;">

$$
\begin{array}{}

w & 4 & 1 & 3 & 2 & 1 & 7\\
q & 4 & 0 & 2 & 0 & 4 & 0\\
編號 & 1 & 2 & 3 & 4 & 5 & 6\\\hline
king & \times & \checkmark & \times & \checkmark & \times & \checkmark \\
fans & 0 & 1 & 0 & 2 & 0 & 0\\
follows & [] & [3] & [] & [1,5] & [] & []
\end{array}
$$

## 程式碼

### 1. 動態規劃

```cpp
#include <iostream>
using namespace std;

const int MX_N = 32001;
const int MX_M = 61;

int cost[MX_M];
int val[MX_M];

bool king[MX_M];
int fans[MX_M]{}; // 記錄附加商品的數量, 初始化為 0
int follows[MX_M][2]; // 最多只有兩個附加商品

int dp[MX_M][MX_N]; // dp[i][j] 代表在商品 v[1...i] 之間, 預算 <= j 的條件下，可以獲取的最大收益。

int main(void) {
    int n, m;
    int v, w, q;

    cin >> n >> m;
    for(int i = 1; i <= m; i++) { // i 為商品編號, 從 1 開始
        cin >> v >> w >> q;
        cost[i] = v;
        val[i] = v * w;
        king[i] = q == 0;
        if(q != 0) {
            follows[q][fans[q]++] = i;
        }
    }

    int p = 0; // 上次展開的主商品編號
    for(int i = 1; i <= m; i++) {
        if(!king[i]) continue; // 跳過附加商品
        for(int j = 0; j <= n; j++) {
            // 不選擇商品 v[i]
            dp[i][j] = dp[p][j]; // 如果是 dp[i - 1], 如果上個商品是附商品，都會是 0

             // 選擇商品 v[i]，枚舉所有可能的選擇方法
            for(int k = 0; k <= (1<<fans[i]) - 1; k++) {
                int addCost = 0;
                int addVal = 0;
                for(int l = 0; l < fans[i]; l++) {
                    if((k>>l) & 1) {
                        addCost += cost[follows[i][l]];
                        addVal += val[follows[i][l]];
                    }
                }
                int remain = j - (cost[i] + addCost);
                if(remain >= 0) {
                    dp[i][j] = max(dp[i][j], dp[p][remain] + val[i] + addVal);
                }
            }
        }
        p = i; // 更新 p
    }
    cout << dp[p][n];
}
```

### 2. 空間壓縮

```cpp
#include <iostream>
using namespace std;

const int MX_N = 32001;
const int MX_M = 61;

int cost[MX_M];
int val[MX_M];

bool king[MX_M];
int fans[MX_M]{}; // 記錄附加商品的數量, 初始化為 0
int follows[MX_M][2]; // 最多只有兩個附加商品

int dp[MX_N]; // dp[j] 代表在預算 <= j 的條件下，可以獲取的最大收益。

int main(void) {
    int n, m;
    int v, w, q;

    cin >> n >> m;
    for(int i = 1; i <= m; i++) { // i 為商品編號, 從 1 開始
        cin >> v >> w >> q;
        cost[i] = v;
        val[i] = v * w;
        king[i] = q == 0;
        if(q != 0) {
            follows[q][fans[q]++] = i;
        }
    }

    for(int i = 1; i <= m; i++) {
        if(!king[i]) continue; // 跳過附加商品
        for(int j = n; j >= cost[i]; j--) {
            // dp[j] 只會因為主商品而更新, 不選擇商品相當於 dp[j] = dp[j]
            // 選擇商品 v[i]，枚舉所有可能的選擇方法
            for(int k = 0; k <= (1<<fans[i]) - 1; k++) {
                int addCost = 0;
                int addVal = 0;
                for(int l = 0; l < fans[i]; l++) {
                    if((k>>l) & 1) {
                        addCost += cost[follows[i][l]];
                        addVal += val[follows[i][l]];
                    }
                }
                int remain = j - (cost[i] + addCost);
                if(remain >= 0) {
                    dp[j] = max(dp[j], dp[remain] + val[i] + addVal);
                }
            }
        }
    }
    cout << dp[n];
}
```

## 複雜度分析

- 時間複雜度：$O(nm)$
- 空間複雜度：空間壓縮前 $O(nm)$，空間壓縮後 $O(n)$
