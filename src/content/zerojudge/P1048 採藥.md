## 思路

此題是經典的01背包問題，也就是物品只有兩種情況，要或不要兩種。\
定義`dp[i][j]`代表在前`i`個草藥中，總時間花費在`j`以下，可以獲得到的最佳價值。\
對於一個新的草藥，有兩種選擇：選或不選。

- 不選：即`dp[i-1][j]`。
- 選：`dp[i][j-t] + val`，其中，`t`、`val`代表採草藥花費的時間與得到的價值。
  - 先決條件：有足夠的時間去採這個草藥，也就是`j-t>0`。

```cpp title="採藥 動態規劃"
#include <iostream>
#include <algorithm>
using namespace std;

const int MX_M = 101;
const int MX_T = 1001;
int dp[MX_M][MX_T]; // dp[i][j] 代表在選項有前 i 個草藥中，總時間花費在 j 之內，可以採到的草藥最大總價值。

int main(void) {
    int T, M;
    cin >> T >> M;

    int t, val; // 採藥需要的時間跟對應的價值
    for(int i = 1; i <= M; i++) {
        cin >> t >> val;
        for(int j = 0; j <= T; j++) {
            dp[i][j] = dp[i - 1][j];
            if(j >= t) { // 時間夠我去採藥, 可以選擇採這個藥草
                dp[i][j] = max(dp[i][j], dp[i - 1][j - t] + val);
            }
        }
    }
    cout << dp[M][T];
}
```

計算`dp[i][j]`時，它依賴`dp[i][≦j]`的格子，可以用這個性質做到空間壓縮。

```cpp title="空間壓縮"
#include <iostream>
#include <algorithm>
using namespace std;

const int MX_T = 1001;
int dp[MX_T]; // dp[j] 代表總時間花費在 j 之內，可以採到的草藥最大總價值。

int main(void) {
    int T, M;
    cin >> T >> M;

    int t, val; // 採藥需要的時間跟對應的價值
    for(int i = 1; i <= M; i++) {
        cin >> t >> val;
        for(int j = T; j >= t; j--) { // 倒序更新, 並確保時間夠我去採藥, 可以選擇採這個藥草
            dp[j] = max(dp[j], dp[j - t] + val);
        }
    }
    cout << dp[T];
}
```

## 複雜度分析

- 時間複雜度：$O(MT)$
- 空間複雜度：空間壓縮前 $O(MT)$，空間壓縮後 $O(T)$
