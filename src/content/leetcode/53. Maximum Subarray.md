## 思路

在數組當中選擇連續的一段，要求這一段的合最大。
定義`dp[i]`代表以`nums[i]`為結尾的最大子數組和，每個位置的更新方式如下：

1. 延續之前的數組合：`dp[i-1] + nums[i]`
2. 以自己做為新的起點：`nums[i]`

- 在上面兩種情況中選比較好的作為答案（`dp[i-1]`可能為負數）

最後在`dp[0...n-1]`中選擇最大值就是答案。

### 1. 動態規劃

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(n); // dp[i] 代表以 nums[i] 為結尾的最大子數組合
        dp[0] = nums[0];
        for(int i = 1; i < n; i++)  {
            dp[i] = max(nums[i], dp[i - 1] + nums[i]);
        }
        return ranges::max(dp);
    }
};
```

### 2. 空間壓縮

每次只會用到`dp[i-1]`這個格子的內容，因此能做到空間壓縮。可以很容易注意到，在取最大值的過程中，只要`last < 0`，那麼它就是來拖後腿的，絕對不會選擇合併。

最後，可以進一步的省去變數`last`。

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int n = nums.size();
        int last = nums[0];
        int res = last;
        int cur;
        for(int i = 1; i < n; i++)  {
            cur = max(nums[i], last + nums[i]);
            last = cur;
            res = max(res, cur);
        }
        return res;
    }
};
```

```cpp title="空間壓縮 2"
class Solution {

```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：空間壓縮前 $O(n)$，空間壓縮後 $O(1)$

## 附加問題

除了找到最大數值之外，還要一併找到這個最大子數組的開頭`left`跟結尾`right`。如果有多個子數組滿足，隨便選擇一種回傳。

---

上面的過程中，`last`更新有兩種方案，往左延續，與自己作為新起點。

- 如果應該要往左延續，代表右邊界可以繼續擴張，移動右指針。
- 如果以自己作為起點比較好，重置左右指針到當前位置。
- 如果更新`res`，表示找到了一個更好的答案，當前的雙指針是此子數組的兩邊界。

```cpp title="附加問題"
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int n = nums.size();
        int last = nums[0];
        int res = last;

        int bestLeft = 0, bestRight = 0;
        int left = 0, right = 0;
        for(int i = 1; i < n; i++)  {
            if(last > 0) {
                last += nums[i];
                right = i;
            }
            else {
                last = nums[i];
                left = right = i;
            }
            if(last > res) {
                bestLeft = left;
                bestRight = right;
                res = last;
            }
        }
        cout << bestLeft << " " << bestRight << endl;
        return res;
    }
};
```
