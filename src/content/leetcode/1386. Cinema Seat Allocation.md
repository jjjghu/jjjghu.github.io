## 思路

可以很直觀的想到，利用哈希表紀錄當前那些位置有被預訂，然後再根據題目意思，去檢查有沒有連續四個位置可以坐的。

```cpp title="哈希表記錄位置資訊"
class Solution {
public:
    int maxNumberOfFamilies(int n, vector<vector<int>>& reservedSeats) {

        map<pair<int, int>, bool> umap;

        for(auto s : reservedSeats) {
            int r = s[0], c = s[1];
            umap[{r, c}] = true; // 標記為被預訂
        }

        int res = 0;
        for(int i = 1; i <= n; i++) { // 1-indexed
            bool left = umap.find({i, 2}) == umap.end() &&
                        umap.find({i, 3}) == umap.end() &&
                        umap.find({i, 4}) == umap.end() &&
                        umap.find({i, 5}) == umap.end();
            bool mid = umap.find({i, 4}) == umap.end() &&
                       umap.find({i, 5}) == umap.end() &&
                       umap.find({i, 6}) == umap.end() &&
                       umap.find({i, 7}) == umap.end();
            bool right = umap.find({i, 6}) == umap.end() &&
                         umap.find({i, 7}) == umap.end() &&
                         umap.find({i, 8}) == umap.end() &&
                         umap.find({i, 9}) == umap.end();
            if(left && right) {
                res += 2;
            } else if(left || mid || right) {
                res++;
            }
        }
        return res;
    }
};
```

這樣做會超時，原因是花費太多常數時間，每次查詢跟取用都會花費掉許多時間。\
為了避免每次查詢都花費過多時間，我們能用位圖來取代哈希表，加速運算。

```cpp title="位圖"
class Solution {
public:
    int maxNumberOfFamilies(int n, vector<vector<int>>& reservedSeats) {

        vector<int> bset(n); // 一個位元代表一個一列的位置狀態

        for(auto s : reservedSeats) {
            int r = s[0] - 1, c = s[1] - 1;
            bset[r] |= (1<<c);
        }


        int res = 0;
        int leftMask = 0b0111100000;  //0011 1100 0000
        int midMask = 0b0001111000;   //0000 1111 0000
        int rightMask = 0b0000011110; //0000 0011 1100

        for(int i = 0; i < n; i++) { // 1-indexed
            // printf("bset[%d] = %010b", i, bset[i]);
            if((bset[i] & (leftMask | rightMask)) == 0) {
                res += 2;
                // cout << " add 2";
            } else if(!(bset[i] & leftMask) || !(bset[i] & midMask) || !(bset[i] & rightMask)) {
                res++;
                // cout << " add 1";
            } else {
                // cout << " add 0";
            }
            // cout << "\n";
        }
        return res;
    }
};
```

這樣做的結果是記憶體不足，因為位圖在初始化時會用掉`n`的空間，而`n`最多可以到 $10^9$\
在初始化時就會導致記憶體用量過多。

在資料範圍中，我們可以看到被預訂的位置至多為 $10^4$，相對於`n`來說非常小，也就代表有非常多列是完全沒有人預訂的空列，可以完整放下兩個四人組。

因此位圖只需要紀錄那些有被預訂的列，其他的空列就不去理會。

### 1. 位圖 + 哈希表

```cpp
class Solution {
public:
    int maxNumberOfFamilies(int n, vector<vector<int>>& reservedSeats) {

        unordered_map<int, int> bset; // bset[列編號] 對應當前列的預定狀態

        for(auto s : reservedSeats) {
            int r = s[0] - 1, c = s[1] - 1;
            bset[r] |= (1<<c);
        }


        int res = 2 * (n - bset.size()); // 沒人預定的列可以加入兩組人
        int leftMask = 0b0111100000;  //0011 1100 0000
        int midMask = 0b0001111000;   //0000 1111 0000
        int rightMask = 0b0000011110; //0000 0011 1100
        for(auto [k, v] : bset) {
            if((v & (leftMask | rightMask)) == 0) {
                res += 2;
            } else if(!(v & leftMask) || !(v & midMask) || !(v & rightMask)) {
                res++;
            }
        }
        return res;
    }
};
```

### 2. 程式碼優化

```cpp
class Solution {
public:
    int maxNumberOfFamilies(int n, vector<vector<int>>& reservedSeats) {

        unordered_map<int, int> bset; // bset[列編號] 對應當前列中, 2 ~ 9 位置的預定狀態

        for(auto s : reservedSeats) {
            int r = s[0], c = s[1];
            if(2 <= c && c <= 9) {
                bset[r] |= 1 << (c - 2);
            }
        }


        int res = 2 * (n - bset.size()); // 沒人預定的列可以加入兩組人
        for(auto& [_, v] : bset) {
            // 因為 1, 10 座位打從一開始就沒有被記錄到位圖中，可以省去一個判斷。
            if(!(v & 0b1111) || !(v & 0b111100) || !(v & 0b11110000)) {
                res++;
            }
        }
        return res;
    }
};
```

## 複雜度分析

> K 代表 `reservedSeats` 的數量。

- 時間複雜度：$O(K)$
- 空間複雜度：$O(K)$
