## 思路

給你一個由數字組成的字串，比如`120345`，返回可以解碼出的字串。
上面的字串可以解碼成`1|20|3|4|5`，對應到英文是`AUCDE`。
解碼時，如果遇到不合法的數字，就視為無法解碼，比如`34`，注意如`03`這種形式不能視為`C`，而是不合法。

---

$$
s="120345"
$$

定義遞迴函數`dfs(i)`代表從`s[i] ~ s[n - 1]`的解碼方法總數。

- `dfs(0)`：在位置 0 的地方，可以決定要結算一個或兩個字元。
  - 一個字元：`1|20345`，相當於`dfs(1)`。
  - 兩個字元：`12|0345`，相當於`dfs(2)`。
    ※ 兩個都合法，因此`dfs(0) = dfs(1) + dfs(2)`。
- `dfs(1)`：在位置 1 的地方，同樣可以決定結算一個或兩個字元
  - 一個字元：`12|0345`，相當於`dfs(2)`。
  - 兩個字元：`120|345`，相當於`dfs(3)`。
    ※ 兩個都合法，因此`dfs(1) = dfs(2) + dfs(3)`
- `dfs(2)`：在位置 2 的地方，同樣可以決定一個或兩個字元
  - 一個字元：`120|345`，相當於`dfs(3)`。
  - 兩個字元：`1203|45`，相當於`dfs(4)`。
    ※ 兩個都不合法，因此`dfs(2) = 0`。

後續以此類推，可以想一下終止條件為什麼是 $1$ 。

$$
\text{dfs}(i)=\begin{cases}
1 & i\geq{n}\\
\text{dfs}(i+1)+\text{dfs}(i+2) & 0\leq{i}<n
\end{cases}
$$

> 注意上面的算式不夠完整，還要連同字串 s 的內容一併考慮。

### 程式碼

```cpp title="解碼方法 暴力遞迴"
class Solution {
public:
    int numDecodings(string s) {
        int n = s.length();

        // dfs(i) 代表從 s[i] ~ s[n - 1] 的解法方法總數
        auto dfs = [&](this auto&&dfs, int i) {
            if(i == n) { // 越界
                return 1;
            }
            if(s[i] == '0') return 0; // 0 開頭必定不合法

            int res += dfs(i + 1); // 不是 0, 剩下情況 1~9 一定合法
            if(i + 1 < n) {
                int code = 10 * (s[i] - '0') + (s[i + 1] - '0');
                if(0 < code && code <= 26) { // 合法編號
                    res += dfs(i + 2);
                }
            }
            return res;
        };

        return dfs(0);
    }
};
```

```cpp title="解碼方法 記憶化搜索"
class Solution {
private:
    static const int MX = 101;
    int dp[MX];
public:
    int numDecodings(string s) {
        int n = s.length();
        fill(dp, dp + n + 1, -1);

        // dfs(i) 代表從 s[i] ~ s[n - 1] 的解法方法總數
        auto dfs = [&](this auto&&dfs, int i) {
            if(i == n) { // 越界
                return 1;
            }
            if(s[i] == '0') return 0; // 0 開頭必定不合法

            int& res = dp[i]; // 注意這裡是引用
            if(res != -1) { // 已經算過了
                return res;
            }

            res = dfs(i + 1); // 不是 0, 剩下情況 1~9 一定合法
            if(i + 1 < n) {
                int code = 10 * (s[i] - '0') + (s[i + 1] - '0');
                if(0 < code && code <= 26) {
                    res += dfs(i + 2);
                }
            }
            return res;
        };

        return dfs(0);
    }
};
```

```cpp title="解碼方法 遞推"
class Solution {
private:
    static const int MX = 101;
    int dp[MX]{};
public:
    int numDecodings(string s) {
        int n = s.length();
        // dp[i] 代表從 s[i] ~ s[n - 1] 的解法方法總數
        dp[n] = 1;
        for(int i = n - 1; i >= 0; i--) {
            if(s[i] == '0') { // 0 開頭必定不合法
                dp[i] = 0;
                continue;
            }
            dp[i] = dp[i + 1];
            if(i + 1 < n) {
                int code = 10 * (s[i] - '0') + (s[i + 1] - '0');
                if(0 < code && code <= 26) {
                    dp[i] += dp[i + 2];
                }
            }
        }
        return dp[0];
    }
};
```

```cpp title="解碼方法 空間壓縮"
class Solution {
public:
    int numDecodings(string s) {
        int n = s.length();
        // dp[i] 代表從 s[i] ~ s[n - 1] 的解法方法總數
        int next2 = 1; // dp[n] = 1;
        int next1 = 1;
        int cur;
        for(int i = n - 1; i >= 0; i--) {
            if(s[i] == '0') { // 0 開頭必定不合法
                cur = 0;
            }
            else {
                cur = next1;
                if(i + 1 < n) {
                    int code = 10 * (s[i] - '0') + (s[i + 1] - '0');
                    if(0 < code && code <= 26) {
                        cur += next2;
                    }
                }
            }
            next2 = next1;
            next1 = cur;
        }
        return cur;
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：空間壓縮前 $O(n)$, 壓縮後 $O(1)$
