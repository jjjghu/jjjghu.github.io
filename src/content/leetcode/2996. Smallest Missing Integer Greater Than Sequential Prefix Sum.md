## 思路

按照題目要求，先算出順序前綴和`x`，再排序數組，找沒出現在`nums`中，大於等於`x`的最小數值。

### 模擬

```cpp
class Solution {
public:
    int missingInteger(vector<int>& nums) {
        int n = nums.size();
        int maxSum = nums[0];
        for(int i = 1; i < n; i++) {
            if(nums[i] - 1 == nums[i - 1]) {
                maxSum += nums[i];
            }
            else {
                break;
            }
        }
        ranges::sort(nums);
        for(int i = 0; i < n; i++) {
            if(nums[i] == maxSum) {
                maxSum++;
            }
        }
        return maxSum;
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n\log{n})$，主要花在排序數組。
- 空間複雜度：$O(1)$
