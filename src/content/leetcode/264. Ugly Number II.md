## 思路

與其一個個去嘗試數字是不是醜數，或是透過`bfs`每次選最小展開。利用動態規劃的方法能更簡單的找到下一個醜數。

建立三個指針`i`、`j`、`k`，分別代表乘以 2、3、5三種可能性。現在要找到下一個數字時，就是將各指針指向的數字，乘以指針倍數後選擇最小的。最後更新指針。說的有點抽象，舉個例子。

---

- $[1,\cdots]$ ，`i=0`、`j=0`、`k=0`。
  - 下一個醜數是 $\min(nums[i]\times2, nums[j]\times3, nums[k]\times5]) = 2$
  - 指針`i`對應的數值是`nums[i] * 2`，沒有比當前最大醜數大，表示它不可能會是下一個醜數，移動`i`指針，直到對應的數值比當前醜數大。
- $[1,2,\cdots]$ ，`i=1`、`j=0`、`k=0`.
  - 下一個醜數是 $\min(nums[i]\times2,nums[j]\times3,nums[k]\times5)=3$
  - 指針`j`對應的數值沒有比當前最大醜數大，表示它不可能是下一個醜數，移動`j`指針，直到對應數值比當前醜數大。
- $[1,2,3,\cdots]$ ，`i=1`、`j=1`、`k=0`
  - 下一個醜數是 $\min(nums[i]\times2,nums[j]\times3,nums[k]\times5)=4$
  - 按照之前的方法更新指針`i`。
- $[1,2,3,4,\cdots]$ ，`i=2`、`j=1`、`k=0`
  - 下一個醜數是 $\min(nums[i]\times2,nums[j]\times3,nums[k]\times5)=5$
  - 按照之前的方法更新指針`k`
- $[1,2,3,5,\cdots]$ ，`i=2`、`j=1`、`k=1`
  - 下一個醜數是 $\min(nums[i]\times2,nums[j]\times3,nums[k]\times5)=6$
  - 指針`i`、`j`對應的數值 $nums[i]\times2,nums[j]\times3$ 都是 6，因此都要移動指針
- $[1,2,3,5,\cdots]$ ，`i=3`、`j=2`、`k=1`，以此類推。

推一推就會發現，每次移動指針最多只會移動一個位置。

### 程式碼

```cpp
class Solution {
public:
    int nthUglyNumber(int n) {
        vector<int> dp(n);
        dp[0] = 1; // 第一個醜數是 1
        int i = 0, j = 0, k = 0;
        for(int idx = 1; idx < n; idx++) {
            dp[idx] = ranges::min({2 * dp[i], 3 * dp[j], 5 * dp[k]});
            if(dp[idx] == 2 * dp[i]) {
                i++;
            }
            if(dp[idx] == 3 * dp[j]) {
                j++;
            }
            if(dp[idx] == 5 * dp[k]) {
                k++;
            }
        }
        return dp[n - 1];
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：$O(1)$
