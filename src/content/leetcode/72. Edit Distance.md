## 思路

> 動態規劃的方案，終究還是得靠自己想，下面的筆記並不是一氣呵成，而是修改了一陣才寫出來的，是思考後所剩下來的筆記，並不是靈光一閃就蹦出來的。\本題在描述上是閹割版，將刪除、插入、替換這三種操作的成本都視為相同。實際上完整版本中，三種操作對應到不同的代價`a`、`b`、`c`。

定義`dp[len1][len2]`代表將`s1[0...len1-1]`轉成`s2[0...len2-1]`的最少代價。\
再看求出`dp[len1][len2]`時，能否用規模較小的子問題，來輔助算出答案？

1. 如果最後一個字元相同，不需要做出任何操作。

- 成本相當於`dp[len-1][len2-1]`。
  > s1 = abce, s2 = abcde, 忽略最後的e，把 abc > abcd 的最小成本即為答案

2. 如果最後一個字元不同，有刪除、插入、替換三種操作。

- 第一種方法，直接轉換最後一個字元，成本`dp[len1-1][len2-1] + c`
  > s1 = abcd, s2 = abce, 把最後一個字元 d > e
- 第二種方法，先刪除再加入，成本`dp[len1-1][len2-1]+ a + b`
  > s1 = xybd, s2 = abce, xyb 轉 abc 後，刪除 d 後再新增 e
- 第三種方法，將`s1[len-1]`視為多的字元，成本`dp[len-1][len2] + a`
  > s1 = xybd, s2=abce, xyb 轉 abce, 多的 d 刪掉
- 第四種方法，將`s2[len2-1]`視為要新增的字元，成本`dp[len][len2-1] + b`
  > s1 = xybd, s2 = abce, xybd 轉 abc, 新增 e

## 程式碼

### 1. 動態規劃 遞推

```cpp
class Solution {
private:
    static const int MX = 501;
    int dp[MX][MX];
public:
    int minDistance(string word1, string word2) {
        return minDistance(word1, word2, 1, 1, 1);
    }

    int minDistance(string& word1, string& word2, int a, int b, int c) {
        // a 刪除, b 插入, c 替換
        int n = word1.length();
        int m = word2.length();
        dp[0][0] = 0;
        for(int j = 1; j <= m; j++) {
            dp[0][j] = dp[0][j - 1] + b;
        }
        for(int i = 1; i <= n; i++) {
            dp[i][0] = dp[i - 1][0] + a;
        }
        for(int i = 1; i <= n; i++) {
            for(int j = 1; j <= m; j++) {
                if(word1[i - 1] == word2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1];
                }
                else {
                    int temp1 = min(dp[i - 1][j - 1] + c, dp[i - 1][j - 1] + a + b);
                    int temp2 = min(dp[i - 1][j] + a, dp[i][j - 1] + b);
                    dp[i][j] = min(temp1, temp2);
                }
            }
        }

        // testPrint(n, m);
        return dp[n][m];
    }

    void testPrint(int n, int m) {
        for(int i = 0; i <= n; i++) {
            for(int j = 0; j <= m; j++) {
                cout << dp[i][j] << " ";
            }
            cout << endl;
        }
    }
};
/*

(n)

ros > horse
1. ro > hors , 直接替換, 消耗 c
2. ro > hors , 刪除再插入, 消耗 a + b
3. ro > horse, 刪除多餘字元, 消耗 a
4. ros > hors, 新增最後字元, 消耗 b
```

### 2. 動態規劃 簡化

題目中的`a`、`b`、`c`都是 1，能藉此稍微簡化程式碼。

```cpp
class Solution {
private:
    static const int MX = 501;
    int dp[MX][MX];
public:
    int minDistance(string& word1, string& word2) {
        int n = word1.length();
        int m = word2.length();
        iota(dp[0], dp[0] + m + 1, 0);
        for(int i = 1; i <= n; i++) {
            dp[i][0] = i;
        }
        for(int i = 1; i <= n; i++) {
            for(int j = 1; j <= m; j++) {
                if(word1[i - 1] == word2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1];
                }
                else {
                    dp[i][j] = min({dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1]}) + 1;
                }
            }
        }
        return dp[n][m];
    }
};
```

### 3. 空間壓縮

最後，更新`dp`格子的過程中，只會用到上一列的數值，能藉此壓縮空間，只留一列，並用變數紀錄左上角格子的數值。

```cpp
class Solution {
private:
    static const int MX = 501;
    int dp[MX];
public:
    int minDistance(string& word1, string& word2) {
        int n = word1.length();
        int m = word2.length();
        // 若使用動態記憶體配置，可以交換 word1, word2 讓使用的空間更小
        iota(dp, dp + m + 1, 0);
        for(int i = 1; i <= n; i++) {
            int leftup = dp[0];
            dp[0] = i;
            for(int j = 1; j <= m; j++) {
                int backup = dp[j];
                if(word1[i - 1] == word2[j - 1]) {
                    dp[j] = leftup;
                }
                else {
                    dp[j] = min({leftup, dp[j], dp[j - 1]}) + 1;
                }
                leftup = backup;
            }
        }
        return dp[m];
    }
};
```

## 複雜度分析

- 時間複雜度：$O(mn)$
- 空間複雜度：空間壓縮前 $O(mn)$，壓縮後 $O(m)$
