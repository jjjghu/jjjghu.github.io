## 思路

定義 `dp[i]` 代表子數組以 `nums[i]` 為尾端，所能得到的最大乘積。
同樣的，可以接續前面的數值，或是自己另起爐灶。先不考慮有負數的情形。

1. 延續前面的數值乘積：`dp[i-1] × nums[i]`
2. 以自己為起點：`nums[i]`

---

加上負數的情形後，擴充 `dp[i]`，除了最大乘積外，也一同記錄最小乘積，因為可能負負得正。
`dp[i][0]`代表以 `nums[i]` 為尾端，所能得到的最大乘積。
`dp[i][1]`代表以 `nums[i]` 為尾端，所能得到的最大乘積。
因此，以下三個數值中，取最大值就是 `dp[i-1][0]`，最小值就是 `dp[i-1][1]`

- `dp[i-1][0] × nums[i]`
- `dp[i-1][1] × nums[i]`
- `nums[i]`

每次只會用到上一行的數值，因此可以用滾動更新的方式省空間。另外，可以根據 `nums[i]` 是正是負，來節省無效的大小比較。

## 程式碼

### 1. 動態規劃

```cpp title="動態規劃"
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int n = nums.size();
        vector<array<int, 2>> dp(n);
        dp[0][0] = nums[0];
        dp[0][1] = nums[0];
        for(int i = 1; i < n; i++) {
            dp[i][0] = max({dp[i - 1][0] * nums[i], dp[i - 1][1] * nums[i], nums[i]});
            dp[i][1] = min({dp[i - 1][0] * nums[i], dp[i - 1][1] * nums[i], nums[i]});
        }
        int res = INT_MIN;
        for(int i = 0; i < n; i++) {
            res = max(res, dp[i][0]);
        }
        return res;
    }
};
```

### 2. 滾動更新

```cpp
class Solution {
public:
    int maxProduct(vector<int>& nums) {
        int n = nums.size();
        int res = nums[0];
        int lastmn = nums[0], mn = nums[0];
        int lastmx = nums[0], mx = nums[0];
        for(int i = 1; i < n; i++) {
            if(nums[i] > 0) { // 不會變號
                mx = max(lastmx * nums[i], nums[i]);
                mn = min(lastmn * nums[i], nums[i]);
            }
            else { // 會變號
                mx = max(lastmn * nums[i], nums[i]);
                mn = min(lastmx * nums[i], nums[i]);
            }
            lastmx = mx;
            lastmn = mn;
            res = max(res, mx);
        }
        return res;
    }
};

```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：空間壓縮前 $O(n)$，空間壓縮後 $O(1)$
