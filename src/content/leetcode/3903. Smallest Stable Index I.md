## 思路

按照題目要求，事先計算好所有 `min(nums[i...n-1])`的數值，並找出滿足條件的最小穩定下標。

## 程式碼

### 前綴和

```cpp
class Solution {
public:
    int firstStableIndex(vector<int>& nums, int k) {
        int n = nums.size();
        vector<int> suffix(n, INT_MAX); // suffix[i] 代表 min(nums[i...n-1])
        suffix[n - 1] = nums[n - 1];
        for(int i = n - 2; i >= 0; i--) {
            suffix[i] = min(suffix[i + 1], nums[i]);
        }

        int res = -1;
        int mx = nums[0];
        for(int i = 0; i < n; i++) {
            mx = max(mx, nums[i]); // mx = max(nums[0...i]);
            if(mx - suffix[i] <= k) {
                res = i;
                break;
            }
        }

        return res;
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：$O(n)$
