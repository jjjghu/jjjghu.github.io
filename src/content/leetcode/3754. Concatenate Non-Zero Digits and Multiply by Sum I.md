## 思路

按照題目敘述，分別將`x`與`sum`求出並相乘即可。\
各自都不會超過`int`的範圍，只要在答案記得轉換即可。

## 程式碼

### 位運算 + 模擬

```cpp
class Solution {
public:
    long long sumAndMultiply(int n) {
        int x = 0;
        int sum = 0;
        int mpy = 1;
        while(n) {
            int digit = n % 10;
            if(digit) {
                x += digit * mpy;
                mpy *= 10;
            }
            sum += digit;
            n /= 10;
        }
        return 1LL * x * sum;
    }
};
```

## 複雜度分析

- 時間複雜度：$O(\log{n})$
- 空間複雜度：$O(\log{n})$
