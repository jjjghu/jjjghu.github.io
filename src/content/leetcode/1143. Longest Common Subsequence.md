## 思路

- $text1:abc12dc345$
- $text2:xyz1y2345g$

上面的例子中，答案是 5，對應到12345這個子字串。

---

從暴力遞迴開始。\
定義`dfs(i, j)`代表`text1[0...i]` 跟 `text2[0...j]`的最長公共子序列長度。

1. 選擇`text1[0...i]`與`text2[0...j-1]`的最長公共子序列長度。
   - $text1:abc12dc345$
   - $text2:xyz1y2345g$
   - `dfs(i, j)` = `dfs(i, j - 1)`

2. 選擇`text1[0...i-1]`與`text2[0...j]`的最長公共子序列長度。
   - $text1:0000x$
   - $text2:000y0$
   - `dfs(i, j)` = `dfs(i - 1, j)`

3. 選擇`text1[0...i-1]`與`text2[0...j-1]`的最長公共子序列長度。
   - $text1:0000x$
   - $text2:0000y$
   - `dfs(i, j)` = `dfs(i - 1, j - 1)`

4. `text1[i] = text2[j]`，那麼參考答案多一項。
   - $text1:0000x$
   - $text2:0000x$
   - `dfs(i, j)` = `dfs(i - 1, j - 1) + 1`

綜合以上，想知道`dfs(i, j)`，先要知道`dfs(i-1, j)`、`dfs(i, j-1)`、`dfs(i-1, j-1)`的數值。

---

如果第四種情況的條件成立，它會不會是參考答案中最好的一個？\
首先第三種情況的答案肯定要比第四種差。\
再來，第二種與第四種情況相比，只多考慮了一個字元`text2[j]`，最長公共子序列相比第三種情況，最多只會增加一。\
第一種情況與第二種情況。因此得出結論：

- $dfs(i-1,j)\leq dfs(i-1,j-1)+1$
- $dfs(i,j-1)\leq dfs(i-1,j-1)+1$
- $dfs(i-1,j-1)< dfs(i-1,j-1)+1$

如果`text1[i] = text2[j]`，`dfs(i-1,j-1)+1`一定是參考答案中最好的那一個。\
同時也知道，第三種情況永遠都會是最糟的那一個答案。

## 程式碼

### 1. 暴力遞迴

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size();
        int n = text2.size();

        // dfs(i, j) 代表 text1[0] ~ text1[i] 跟 text2[0] ~ text2[j] 的最長公共子序列長度
        auto dfs = [&](this auto&&dfs, int i, int j) -> int {
            if(i < 0 || j < 0) {
                return 0;
            }

            int res = 0;
            if(text1[i] == text2[j]) {
                res = dfs(i - 1, j - 1) + 1;
            }
            else {
                res = max(dfs(i - 1, j), dfs(i, j - 1));
            }
            return res;
        };
        return dfs(m - 1, n - 1);
    }
};
```

### 2. 記憶化搜索

會呼叫到相同的子問題，參數簡單，因此加入記憶化搜索，避免重複計算。

```cpp
class Solution {
private:
    static const int MX = 2001;
    int dp[MX][MX];
public:
    int longestCommonSubsequence(string text1, string text2) {
        int m = text1.size();
        int n = text2.size();
        for(int i = 0; i < m; i++) {
            fill(dp[i], dp[i] + n, -1);
        }
        // dfs(i, j) 代表 text1[0] ~ text1[i] 跟 text2[0] ~ text2[j] 的最長公共子序列長度
        auto dfs = [&](this auto&&dfs, int i, int j) -> int {
            if(i < 0 || j < 0) {
                return 0;
            }

            int& res = dp[i][j];
            if(res != -1) {
                return res;
            }

            if(text1[i] == text2[j]) {
                res = dfs(i - 1, j - 1) + 1;
            }
            else {
                res = max(dfs(i - 1, j), dfs(i, j - 1));
            }
            return res;
        };
        return dfs(m - 1, n - 1);
    }
};
```

### 3. 動態規劃 遞推

在前面的推導關係中。想知道`dfs(i, j)`，先要知道`dfs(i-1, j)`、`dfs(i, j-1)`、`dfs(i-1, j-1)`的數值。轉換成遞推時，對應到二維矩陣中，先算好簡單問題，再去算複雜問題，為後面的空間壓縮做準備。

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int n = text1.length();
        int m = text2.length();

        vector<vector<int>> dp(n, vector<int>(m, 0)); // dp[0][0] = 0;


        dp[0][0] = text1[0] == text2[0] ? 1 : 0;

        // 第一行
        for(int i = 1; i < n; i++) {
            dp[i][0] = text1[i] == text2[0] ? 1 : dp[i - 1][0];
        }

        // 第一列
        for(int j = 1; j < m; j++) {
            dp[0][j] = text1[0] == text2[j] ? 1 : dp[0][j - 1];
        }

        for(int i = 1; i < n; i++) {
            for(int j = 1; j < m; j++) {
                if(text1[i] == text2[j]) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                }
                else {
                    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }

        return dp[n - 1][m - 1];
    }
};
```

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        // 讓 text2 的長度是較小的那一個，讓後續開的空間比較小
        if(text1.length() < text2.length()) {
            swap(text1, text2);
        }

        int n = text1.length();
        int m = text2.length();


        vector<int> dp(m, 0);

        dp[0] = text1[0] == text2[0] ? 1 : 0;

        // 第一列
        for(int j = 1; j < m; j++) {
            dp[j] = text1[0] == text2[j] ? 1 : dp[j - 1];
        }

        for(int i = 1; i < n; i++) {
            int leftup = dp[0];
            dp[0] = text1[i] == text2[0] ? 1 : dp[0];
            for(int j = 1; j < m; j++) {
                int backup = dp[j];
                if(text1[i] == text2[j]) {
                    dp[j] = leftup + 1;
                }
                else {
                    dp[j] = max(dp[j], dp[j - 1]);
                }
                leftup = backup;
            }
        }

        return dp[m - 1];
    }
};
```

## 複雜度分析

- 時間複雜度：$O(mn)$
- 空間複雜度：空間壓縮前 $O(mn), 壓縮後 $O(m)$
