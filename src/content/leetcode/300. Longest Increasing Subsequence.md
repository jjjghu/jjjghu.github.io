## 思路

定義`dp[i]`代表以`nums[i]`為結尾的最長遞增子序列長度是多少。

$$
dp[i] = \begin{cases}
\max(dp[j] + 1) & \forall{j<i} ~\text{and}~ nums[j] < nums[i]\\
1 & \text{otherwise}
\end{cases}
$$

1. 情況一：接續前面的序列，可能有很多能接續的來源，選能讓長度最大的。
2. 情況二：自己作為起點，最長遞增子序列是 1

```cpp title="記憶化搜索"
class Solution {
private:
    static const int MX = 2501;
    int dp[MX];
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();
        fill(dp, dp + n + 1, -1);

        // dfs(i) 代表從 nums[0...i] 中, 以 nums[i] 為結尾的最長遞增子序列
        auto dfs = [&](this auto&&dfs, int i) {
            if(i == 0) return 1;

            int& res = dp[i];
            if(res != -1) {
                return res;
            }

            res = 1;
            for(int j = 0; j < i; j++) {
                if(nums[i] > nums[j]) {
                    res = max(res, dfs(j) + 1);
                }
            }
            return res;
        };

        int res = 0;
        for(int i = 0; i < n; i++) {
            res = max(res, dfs(i));
        }
        return res;
    }
};
```

```cpp title="遞推"
class Solution {
private:
    static const int MX = 2501;
    int dp[MX];
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();

        int res = 0;
        for(int i = 0; i < n; i++) {
            dp[i] = 1;
            for(int j = 0; j < i; j++) {
                if(nums[i] > nums[j]) {
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }
            res = max(res, dp[i]);
        }
        return res;
    }
};
```

搜尋`ends`數組時，可以用二分搜尋法，因為它的數值會嚴格遞增。
`ends[i]`代表目前所有長度為`i+1`的遞增子序列的最小結尾。
為甚麼必定是嚴格遞增的？假如 $ends=[1,10,5]$ ，根據定義，我們知道

1. `ends[0]`：長度為 1 的遞增子序列的最小結尾是 1，就是 $[1]$
2. `ends[1]`：長度為 2 的遞增子序列的最小結尾是 10，對應 $[?^1,10]$
3. `ends[2]`：長度為 3 的遞增子序列的最小結尾是 5，對應 $[?^2,?^3,5]$

那麼，根據上面的定義，我們一定能找到兩個長度為 2 的遞增子序列 $[?^2,5], [?^3,5]$ ，因此`ends[1]`不可能是 10。

---

假設`ends[i] = x`，`ends[i+1] = y`

1. `ends[i]`：長度為 `i+1` 的遞增子序列的最小結尾是 $x$ ， $[a_1,a_2,\cdots,x]$
2. `ends[i+1]`：長度為 `i+2` 的遞增子序列的最小結尾是 $y$ ， $[a_1,a_2,\cdots,a_{i+1},y]$

$[a_1,a_2,\cdots,a_{i+1}]$ 是一個長度為 `i+1` 的嚴格遞增子序列，因此必定滿足以下條件。\
$x\leq a_{i+1} < y$ ，因此 $x<y$ 。

### 2. 動態規劃 + 二分搜

```cpp
class Solution {
private:
    static const int MX = 2501;
    int dp[MX]; // dp[i] 代表以 nums[i] 為結尾的最長遞增子序列長度是多少。

    int findPos(vector<int>& ends, int x) { // 在 ends 中, 找到第一個 >= nums[i] 的位置
        int left = 0, right = ends.size() - 1; // 閉區間
        int pos = -1; // 沒找到可行位置
        while(left <= right) {
            int mid = left + (right - left) / 2;
            if(ends[mid] >= x) {
                pos = mid;
                right = mid - 1;
            }
            else {
                left = mid + 1;
            }
        }
        return pos;
    }
public:
    int lengthOfLIS(vector<int>& nums) {
        int n = nums.size();

        vector<int> ends; //
        for(int i = 0; i < n; i++) {
            int pos = findPos(ends, nums[i]);
            if(pos == -1) { // 沒有可行位置, 表示 nums[i] 要比所有數字都大
                ends.push_back(nums[i]);
                dp[i] = ends.size();
            }
            else { // 有可行位置, 將 ends[pos] 取代為 nums[i]
                ends[pos] = nums[i];
                dp[i] = pos + 1; // 可加可不加
            }
        }
        return ends.size();
    }
};
```
