## 思路

需要將排序後的數組所在的位置，重新編號之後給排序前的數組標上編號。

因此在記錄好原始位置後，排序數組。\
接下來按照順序給每個數字給編號，假如與上一個數字相同，給定的編號就不變動\
下面的作法不使用哈希表，能節省許多常數時間。

## 程式碼

### 排序

```cpp
class Solution {
public:
    vector<int> arrayRankTransform(vector<int>& arr) {
        int n = arr.size();
        if(n == 0) return {};
        vector<pair<int,int>> vec; // value, pos
        vec.reserve(n);
        for(int i = 0; i < n; i++) {
            vec.push_back({arr[i], i});
        }
        ranges::sort(vec);
        vector<int> res(n);
        res[vec[0].second] = 1;
        for(int i = 1, id = 1; i < n; i++) {
            if(vec[i - 1].first != vec[i].first) {
                id++;
            }
            res[vec[i].second] = id;
        }
        return res;
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n\log{n})$
- 空間複雜度：$O(n)$
