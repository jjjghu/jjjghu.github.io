## 思路

每一個房子可偷可不偷，但你一但偷了，隔壁的就不能偷。就是不能連續偷兩家，至少要間隔一間房屋。

---

定義 `dfs(i,j)` 代表偷取 `nums[0...i]` 這些屋子能偷到的最高金額。

- 如果`j=0`，代表不偷`nums[i]`。
- 如果`j=1`，代表要偷`nums[i]`。

那麼，想知道`dfs(i,j)`有分為以下幾種情況。

- 如果`j=0`，不偷`nums[i]`，前一家可偷可不偷，選金額高的。
  - 不偷前家：`dfs(i-1,0)`
  - 要偷前家：`dfs(i-1,1)`
- 如果`j=1`，要偷`nums[i]`，前一家不可偷。
  - 不偷前家：`dfs(i-1,0)` + `nums[i]`（本家收益）

### 1. 計液化搜索

```cpp
class Solution {
private:
    static const int MX = 401;
    int dp[MX][2];
public:
    int rob(vector<int>& nums) {
        int n = nums.size();

        for(int i = 0; i < n; i++) {
            dp[i][0] = -1;
            dp[i][1] = -1;
        }

        // 定義 dp[i][j] 代表偷取 nums[0...i] 這些屋子的現金的最高金額
        // j = 0 代表不偷 nums[i], j = 1 代表必須偷 nums[i]
        auto dfs = [&](this auto&&dfs, int i, int j) -> int {
            if(i == 0) {
                return j == 1 ? nums[i] : 0;
            }

            int& res = dp[i][j]; // 注意這裡是引用
            if(res != -1) {
                return res;
            }

            if(j == 1) { // 今天你必須偷這一家
                res = nums[i] + dfs(i - 1, 0); // 前一家必不能偷
            }
            else { // 今天你不准偷
                res = max(dfs(i - 1, 0), dfs(i - 1, 1)); // 前一家可偷可不偷, 選比較好的
            }
            return res;
        };

        return max(dfs(n - 1, 0), dfs(n - 1, 1));
    }
};
```

### 2. 遞推

轉換成遞推，注意到只會用到上一行的數值，可以用滾動更新的方式省空間。

```cpp
class Solution {
private:
    static const int MX = 401;
    int dp[MX][2];
public:
    int rob(vector<int>& nums) {
        int n = nums.size();

        dp[0][0] = 0;
        dp[0][1] = nums[0];
        for(int i = 1; i < n; i++) {
            dp[i][0] = max(dp[i - 1][0], dp[i - 1][1]);
            dp[i][1] = nums[i] + dp[i - 1][0];
        }

        return max(dp[n - 1][0], dp[n - 1][1]);
    }
};
```

假如偷的時候可能偷到「負數」，在前面收益可能為負的情況下，得多考慮單偷此家的情況。

---

另一種理解方式，是定義`dp[i]`代表從`nums[0...i]`隨意選擇數字，滿足條件的最大總和。

1. `dp[i] = dp[i-1]`，代表偏不選這個數字。
2. `dp[i] = dp[i-2] + nums[i]`，代表偏要選這個數字。
3. `dp[i] = nums[i]`，代表只選這個數字。

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if(n == 1) {
            return max(0, nums[0]);
        }
        if(n == 2) {
            return max(0, max(nums[0], nums[1]));
        }
        int prev2 = nums[0]; // dp[0]
        int prev = max(nums[0], nums[1]); // dp[1]
        for(int i = 2; i < n; i++) {
            // 偷前面、只偷這家、偷這家 + 偷 nums[0...i-2]家
            int cur = max(prev, max(nums[i], prev2 + nums[i]));
            prev2 = prev;
            prev = cur;
        }
        return prev;
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：空間壓縮前 $O(n)$，空間壓縮後 $O(1)$
