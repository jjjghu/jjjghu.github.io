## 思路

給定兩個字串，比如`honrail`，與`star`，看能不能拼成目標字串，比如`honkaistarrail`，合併後，字元順序要跟原本的`s1`、`s2`相同。
本題是不能用雙指針的，比如`aaaa`、`aabc`，看能否拼成`aabcaaaa`，單用雙指針，如果指向`aaaa`的指針在前面就移動，後面就會指到尾端，就完蛋了。

---

確保`s1`與`s2`的長度合併後能變成s3的長度。
定義`dp[i][j]`代表`s1[0...i-1]`跟`s2[0...j-1]`能否拼成`s3[0...i+j-1]`。
這裡的 `i`, `j` 代表字串長度，就是前面題目中的 `len1`, `len2`
想算出`dp[i][j]`，也就是看能否拼成`s3[0...i+j-1]`。

- 比如 `s1=hnas`, `s2=okitar`, `s3=honkaistar`。
  - 最後一個位置可以用`s2[5]`，\
    此時只要`dp[4][5]=true`，那麼`dp[4][6] = true`\
    > 用 hnas + sta 合出 okitar, 然後最後一位用 r\

同理，當`s2[j-1] == s3[i+j-1]`時，只要`dp[i][j-1] = true`，那麼`dp[i][j]`就為`true`。

## 程式碼

### 1. 動態規劃 遞推

```cpp
class Solution {
private:
    static const int MX = 101;
    bool dp[MX][MX];
public:
    bool isInterleave(string s1, string s2, string s3) {
        int n = s1.length();
        int m = s2.length();
        if(n + m != s3.length()) return false;
        dp[0][0] = true;

        for(int i = 1; i <= n; i++) {
            dp[i][0] = dp[i - 1][0] && s1[i - 1] == s3[i - 1];
        }

        for(int j = 1; j <= m; j++) {
            dp[0][j] = dp[0][j - 1] && s2[j - 1] == s3[j - 1];
        }

        for(int i = 1; i <= n; i++) {
            for(int j = 1; j <= m; j++) {
                if(dp[i][j - 1] && s2[j - 1] == s3[i + j - 1]) {
                    dp[i][j] = true;
                }
                else if(dp[i - 1][j] && s1[i - 1] == s3[i + j - 1]) {
                    dp[i][j] = true;
                }
                else {
                    dp[i][j] = false;
                }
            }
        }
        return dp[n][m];
    }
};
```

### 2. 空間壓縮

```cpp
class Solution {
private:
    static const int MX = 101;
    bool dp[MX];
public:
    bool isInterleave(string s1, string s2, string s3) {
        int n = s1.length();
        int m = s2.length();
        if(n + m != s3.length()) return false;

        dp[0] = true;
        for(int j = 1; j <= m; j++) {
            dp[j] = dp[j - 1] && s2[j - 1] == s3[j - 1];
        }

        for(int i = 1; i <= n; i++) {
            dp[0] = dp[0] && s1[i - 1] == s3[i - 1];
            for(int j = 1; j <= m; j++) {
                dp[j] = (dp[j - 1] && s2[j - 1] == s3[i + j - 1]) ||
                        (dp[j]     && s1[i - 1] == s3[i + j - 1]);
            }
        }
        return dp[m];
    }
};
```
