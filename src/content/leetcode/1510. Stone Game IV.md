## 思路

定義 `dfs(i)` 代表剩下 `i` 個石頭時，當前玩家是否能勝利。\
Alice 先手，因此題目要找的答案即為 `dfs(n)`。

對於 Alice 來說，自己能拿取的石子數量是 $1^2, 2^2, 3^2,\cdots$ 最多不能超過 `i` 個石子。\
留給 Bob 的局面就會是 $dfs(i-1^2), dfs(i-2^2), dfs(i-3^2),\cdots$，在這些局面中，只要有一個狀態能讓 Bob 輸掉，那麼 Alice 就會選擇拿走對應的石子數量。

> 比如我發現拿走 9 顆石頭能讓 Bob 輸掉，那拿走 9 顆就要比其他的選項好。

遞迴過程中，可能會有重複計算的部分，用記憶化搜索去除重複計算的部分。

### 1. 記憶化搜索

```cpp
class Solution {
private:
    static const int MX = 1e5+1;
    int dp[MX]; // -1 代表沒有計算過這個狀態
public:
    bool winnerSquareGame(int n) {
        fill(dp, dp + n + 1, -1);

        // dfs(i) 代表剩下 i 個石頭時, 當前玩家是否能勝利
        auto dfs = [&](this auto&&dfs, int i) -> bool {
            if(i <= 0) return false; // 沒有石頭可以拿, 輸

            if(dp[i] != -1) {
                return dp[i] > 0 ? true : false;
            }

            for(int x = 1; x * x <= i; x++) {
                if(!dfs(i - x*x)) { // 如果能讓對方輸, 讓他輸
                    dp[i] = 1;
                    return true; // 自己贏
                }
            }
            dp[i] = 0;
            return false; // 自己輸
        };

        return dfs(n);
    }
};
```

### 2. 遞推

```cpp
class Solution {
private:
    static const int MX = 1e5+1;
    bool dp[MX]; // 改為 bool 類型
public:
    bool winnerSquareGame(int n) {
        dp[0] = false; // 沒有石子可以選擇, 面對此局面必輸
        for(int i = 1; i <= n; i++) {
            bool canWin = false;
            for(int x = 1; x * x <= i; x++) {
                if(!dp[i - x*x]) {
                    canWin = true;
                    break;
                }
            }
            dp[i] = canWin;
        }
        return dp[n];
    }
};
```

## 複雜度分析

> 計算 `dp[i]` 時，都需要枚舉平方數，複雜度 $O(\sqrt{n})$

- 時間複雜度：$O(n\sqrt{n})$
- 空間複雜度：$O(n)$
