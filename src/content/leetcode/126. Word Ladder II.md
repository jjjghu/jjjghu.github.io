## 思路

題目要找到單字轉換的最短路徑。\
每次轉換的字串都要在 `wordList` 當中，並且跟原先字串只有一字之差。\
很明顯會用到 `bfs` 去搜索，當搜到目標單字之後， `bfs` 的深度，就是最短路徑長。

---

接下來就要記錄路徑了。若是在 `bfs` 的過程中記錄路徑，會花費許多記憶體，因此需要有個方法省去一些不必要的分支。\
節省分支的方式是dfs，具體來說，是在 `bfs` 時建立一張「反圖」，用來記錄當前字串可以被其他哪些字串轉換過來。\
在 `bfs` 終止時，建立出來的圖當中所包含的資訊，只會有距離最短的多條路徑。\
這時用dfs，找到的路徑一定會是最短的，且節省了許多時間。

## 程式碼

### dfs, bfs

```cpp
class Solution {
private:
    unordered_set<string> dict;
    unordered_set<string> curLevel, nextLevel; // bfs 每層的紀錄
    unordered_map<string, vector<string>> graph; // 反向圖，紀錄那些字串能轉換成自己
    vector<vector<string>> res;
    vector<string> path;
    bool bfs(string beginWord, string endWord) {
        int n = beginWord.length(); // 所有字串長度都相同

        bool found = false;
        curLevel.insert(beginWord);
        while(!curLevel.empty()) {
            for(string s : curLevel) {
                dict.erase(s);
            }
            for(string s : curLevel) {
                string temp = s; // 記憶中的模樣
                for(int i = 0; i < n; i++) { // 更換每一個位置的字元之後到字典查找，若是存在，加入下一層
                    char old = s[i];
                    for(char ch = 'a'; ch <= 'z'; ch++) {
                        if(ch == old) continue; // 不變，跳過
                        s[i] = ch;
                        if(dict.contains(s)) { // 可變化
                            if(s == endWord) found = true;
                            nextLevel.insert(s);
                            graph[s].push_back(temp); // 紀錄變化字串
                        }
                    }
                    s[i] = old; // 恢復以供下次修改
                }
            }
            if(found) {
                return true; // 不能一找到就回傳，否則反圖沒建好
            }
            else {
                curLevel = nextLevel;
                nextLevel.clear();
            }
        }

        return false;
    }
    void dfs(string cur, string target) {
        // 路徑存在, 透過反圖找到
        path.push_back(cur);
        if(cur == target) {
            reverse(path.begin(), path.end());
            res.push_back(path);
            reverse(path.begin(), path.end()); // 還原
        }
        else if(graph.contains(cur)) {
            for(string neighbor : graph[cur]) {
                dfs(neighbor, target);
            }
        }
        path.pop_back();
    }
public:
    vector<vector<string>> findLadders(string beginWord, string endWord, vector<string>& wordList) {
        dict = unordered_set<string>(wordList.begin(), wordList.end());
        if(!dict.contains(endWord)) {
            return {};
        }

        if(bfs(beginWord, endWord)) { // 假如能找到轉換路徑
            dfs(endWord, beginWord); // 就透過 graph 將路徑找出來，加入答案
        }
        return res;
    }
};
```

## 複雜度分析

> N 為字典字數，L為字串長度，K為最短路徑的總條數

- 時間複雜度：
  - BFS 部分 $O(26NL^2)$
  - DFS 部分 $O(KNL)$
- 空間複雜度：$O(2LN^2)$
