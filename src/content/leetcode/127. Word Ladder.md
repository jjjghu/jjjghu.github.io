## 思路

題目[[126]]當中，我們使用了`bfs`跟`dfs`，分別判斷存不存在路徑，以及確切的路徑為何。\
而前者可以透過「雙向`bfs`」去優化，以這題為例，就是從起點跟終點往外擴張，\
一直到兩者「佔領」的區塊有所重疊，就代表起點跟終點有路徑存在。\
以下有單點廣度搜索的寫法作為參照。

雙向廣度優先搜索，為了減少擴展出的分支數量，每次擴展時，都選擇當前比較小的那一方。

- 若 `beginWord` 擴出了 30 個分支，`endWord` 擴出了 20 個分支，這時選擇擴張 `endWord` 那一端。

當自己擴出的單字，已經在對方的集合當中出現時，就表示有路徑存在。\
在檢查是否要繼續擴張時，只需檢查 `smallLevel.empty()`，因為在它為空時，就不可能有路徑通往 `endWord`。

## 程式碼

### 1. 單點 bfs

```cpp
class Solution {
private:
    unordered_set<string> dict;
    unordered_set<string> curLevel, nextLevel;
    int bfs(string beginWord, string endWord) {
        int n = beginWord.length();
        curLevel.insert(beginWord);
        dict.erase(beginWord);
        int level = 1;
        while(!curLevel.empty()) {
            // 刪除可以在檢查時做，而不需要獨立出來，因為不用建反圖，這裡是方便察看結果。
            // 具體見雙向 bfs 解法。
            // cout << level << ": ";
            for(string s : curLevel) {
                // cout << s << " ";
                dict.erase(s);
            }
            // cout << endl;
            for(string s : curLevel) {
                for(int i = 0; i < n; i++) {
                    for(char c = 'a'; c <= 'z'; c++) {
                        if(c == s[i]) continue;
                        char old = s[i];
                        s[i] = c;
                        if(dict.contains(s)) {
                            if(s == endWord) return level + 1; // 要經過 level  次轉換到 endWord, 共 level + 1 個單字
                            nextLevel.insert(s);
                        }
                        s[i] = old;
                    }
                }
            }
            curLevel = nextLevel;
            nextLevel.clear();
            level++;
        }
        return 0;
    }
public:
    int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
        dict = unordered_set<string>(wordList.begin(), wordList.end());
        if(!dict.contains(endWord)) {
            return 0;
        }
        return bfs(beginWord, endWord);
    }
};
```

### 2. 雙向 bfs

```cpp
class Solution {
private:
    unordered_set<string> dict;
    unordered_set<string> smallLevel, bigLevel, nextLevel;
    int bfs(string beginWord, string endWord) {
        int n = beginWord.length();
        smallLevel.insert(beginWord);
        bigLevel.insert(endWord);
        for(int level = 2; !smallLevel.empty(); level++) { // 左邊有一層，右邊有一層，初始層數 2，持續擴張到 smallLevel 為止
            for(string s : smallLevel) {
                for(int i = 0; i < n; i++) {
                    for(char c = 'a'; c <= 'z'; c++) {
                        if(c == s[i]) continue;
                        char old = s[i];
                        s[i] = c;
                        if(bigLevel.contains(s)) {
                            return level;
                        }
                        if(dict.contains(s)) {
                            nextLevel.insert(s);
                            dict.erase(s);
                        }
                        s[i] = old;
                    }
                }
            }
            // 將擴出來的這一層，根據大小，放到 smallLevel 或是 bigLevel 中
            if(nextLevel.size() < bigLevel.size()) {
                smallLevel = nextLevel;
            }
            else {
                smallLevel = bigLevel;
                bigLevel = nextLevel;
            }
            nextLevel.clear();
        }
        return 0;
    }
public:
    int ladderLength(string beginWord, string endWord, vector<string>& wordList) {
        dict = unordered_set<string>(wordList.begin(), wordList.end());
        if(!dict.contains(endWord)) {
            return 0;
        }
        return bfs(beginWord, endWord);
    }
};
```

## 複雜度分析

> N 為 `wordList` 的長度，C 為列表單字的長度

- 時間複雜度：$O(NC^2)$
- 空間複雜度：$O(NC^2)$
