## 思路

相比前面的題目，這道題不太能透過暴力遞迴，來找到重複的子問題。這種時候，就得自己去想子問題的形式，去判斷一下這個「子問題」，能不能滿足以下條件。

- 知道這個子問題的答案，能不能幫助推論較複雜問題的答案？
- 如果可以，該怎麼透過子問題推論？
- 最簡單的子問題該怎麼判斷？

---

以此題為例，定義 $dp[i]$ 代表以 $s[i]$ 為結尾的最長有效括號長度。

$$
\begin{array}{c|c}
s[i] & ( & ( & ) & ( & ) & ) & (\\
idx & 0 & 1 & 2 & 3 & 4 & 5 & 6\\
dp[i] & 0 & 0 & 2 & 0 & 4 & 6 & 0
\end{array}
$$

最後在 $dp$ 表中取最大值，就是最終答案。可以很輕易地發現，只要是`(`，以它結尾長度必定是 0。而`)`的情況就比較複雜。有以下幾種情況：

這四種情況中，都要試著找能配對的括號位置`left`。狀況一還要額外看能否與`left - 1`的括號再繼續相連。另外在狀況三中，有沒有辦法透過`dp[i - 1]`來找到「自己左邊可能配對上的括號」？
`dp[i - 1]`代表以`s[i - 1]`為結尾的最長有效括號長度，也就是說，它可能配對上的括號位置會在`i - 1 - dp[i - 1]`。

1. 第一種情況中，`i`對應的`left = i - 1`
2. 第二種情況中，`i`對應的`left = i - 1`
3. 第三種情況中，`i`對應的`left = i - 1 - dp[i - 1]`
4. 第四種情況中，`i`對應的`left = i - 1`，但沒配對上，答案為 0。

而在前兩種情況中，同樣可以視`left = i - 1 - dp[i - 1]`，只不過因為它們都是左括號，對應到 0。

最後，如果有配對上，要檢查能否繼續向左相連，這個位置就在`left - 1`，寫的時候注意邊界。

> 不會有二次相連的情況，因為要是真能二次相連，dp[left - 1] 所代表的數值，就不是「以 s[left - 1] 為結尾的最長有效括號長度」了。

$$
dp[i] = \begin{cases}
0 & \text{if s[i] = (}\\
left = i - 1 - dp[i - 1] \\
0 & \text{if left < 0 or s[left] = )}\\
dp[i-1]+2+(left\geq0~?~dp[left-1]:0) & \text{otherwise}
\end{cases}
$$

## 程式碼

### 1. 動態規劃

```cpp
class Solution {
private:
    static const int MX = 3e4+1;
    int dp[MX];
public:
    int longestValidParentheses(string s) {
        int n = s.length();
        fill(dp, dp + n, 0); // 左括號都是 0, 就直接預設 0
        for(int i = 1; i < n; i++) { // dp[0] 一定是 0, 從 1 開始
            // if(s[i] == '(') {
            //     dp[i] = 0;
            // }
            if(s[i] == ')') {
                int left = i - 1 - dp[i - 1];
                if(left >= 0 && s[left] == '(') {
                    dp[i] = dp[i - 1] + 2;
                    if(left - 1 >= 0) { // 可能繼續往左連
                        dp[i] += dp[left - 1];
                    }
                }
            }
        }
        return ranges::max(dp | views::take(n + 1));
    }
};
/*
dp[i] = 以 s[i] 為結尾的最長有效括號長度。
*/
```

### 2.單調棧

```cpp
class Solution {
public:
    int longestValidParentheses(string s) {
        int n = s.length();
        stack<int> stk; // 注意紀錄的是 index
        stk.push(-1); // 起點前面一個位置
        int res = 0;
        for(int i = 0; i < n; i++) {
            if(s[i] == '(') {
                stk.push(i);
            }
            else { // s[i] == ')'
                stk.pop();
                if(stk.empty()) {
                    stk.push(i);
                }
                else {
                    res = max(res, i - stk.top());
                }
            }
        }
        return res;
    }
};
```

> 最好的方法是用雙指針，同樣要先經過分析，雙指針只是最後適合的方法，能做到空間 O(1)。
