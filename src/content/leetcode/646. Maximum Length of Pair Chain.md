## 思路

先讓數組根據起始位置排序，接下來要找能接的最長數對鍊，我們在尋找插入位置時，用的是起點的位置，實際放在`ends`中的數值則是數對的結尾。\
拿起點去找第一個 $\leq$ 自己的尾端數字，找到的位置`pos`，就是這個以這個數對為結尾，可以接上的最佳位置。而更新`ends[pos]`時，則要額外判斷尾端數字，只有在能變得更小時才去更新。

```cpp title="動態規劃 + 二分搜"
class Solution {
private:
    static const int MX = 1001;
    int ends[MX]; // ends[i] 代表長度為 i + 1 的最長遞增子序列，對應的最小結尾

    int findPos(int x, int endSize) {
        int pos = -1;
        int left = 0, right = endSize - 1;
        while(left <= right) {
            int mid = left + (right - left) / 2;
            if(ends[mid] >= x) {
                pos = mid;
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        return pos;
    }
public:
    int findLongestChain(vector<vector<int>>& pairs) {
        ranges::sort(pairs, [&](vector<int>& a, vector<int>& b) {
            return a[0] < b[0];
        });

        int n = pairs.size();
        int endSize = 0;
        for(int i = 0; i < n; i++) {
            int pos = findPos(pairs[i][0], endSize);
            if(pos == -1) {
                ends[endSize++] = pairs[i][1];
            } else if(ends[pos] > pairs[i][1]) {
                ends[pos] = pairs[i][1];
            }
        }
        return endSize;
    }
};
```

更簡單的做法，是根據結尾排序，紀錄最小的結尾pre，並貪心的去更新結尾。

```cpp title="排序 + 貪心"
class Solution {
public:
    int findLongestChain(vector<vector<int>>& pairs) {
        ranges::sort(pairs, [&](vector<int>& a, vector<int>& b) {
            return a[1] < b[1];
        });

        int minEnd = INT_MIN;
        int n = pairs.size();
        int res = 0;
        for(int i = 0; i < n; i++) {
            if(minEnd < pairs[i][0]) {
                minEnd = pairs[i][1];
                res++;
            }
        }
        return res;
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n\log{n})$
- 空間複雜度：$O(n)$，貪心 $O(1)$
