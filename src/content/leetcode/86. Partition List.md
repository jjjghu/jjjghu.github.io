## 思路

題目給定一個數字x，要將鏈表當中的節點分割為「小於 `x`」和「大於 `x`」兩部分。

- 建立兩個哨兵節點方便連接，並用兩個尾端節點紀錄「小於 `x`」和「大於`x`」兩部分的節點。
- 在分類完之後將兩個鏈表接起來，最後回傳。

## 程式碼

### 鏈表

```cpp
class Solution {
public:
    ListNode* partition(ListNode* head, int x) {
        ListNode* dummy1 = new ListNode();
        ListNode* tail1 = dummy1;
        ListNode* dummy2 = new ListNode();
        ListNode* tail2 = dummy2;
        while(head != nullptr) {
            ListNode* next = head -> next;
            if(head -> val < x) { // 小於 x 的節點接到 tail1
                tail1 -> next = head;
                tail1 = tail1 -> next;
                tail1 -> next = nullptr;
            }
            else { // >= x 的節點接到 tail2
                tail2 -> next = head;
                tail2 = tail2 -> next;
                tail2 -> next = nullptr;
            }
            head = next;
        }
        tail1 -> next = dummy2 -> next; // 小於 x 的尾端接到大於 x 的節點
        ListNode* res = dummy1 -> next;
        delete dummy1;
        delete dummy2;
        return res;
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：$O(n)$
