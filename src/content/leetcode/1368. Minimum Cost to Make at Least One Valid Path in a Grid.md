## 思路

若當前的行進方向跟箭頭相同，便不會消耗成本。反之則成本加一。\
由於消耗的成本只有 0 或 1，能用 01 bfs 去找出解答。

## 程式碼

### 01BFS

```cpp
class Solution {
public:
    int minCost(vector<vector<int>>& grid) {
        int n = grid.size();
        int m = grid[0].size();
        vector<vector<int>> dist(n, vector(m, INT_MAX));
        dist[0][0] = 0;
        deque<pair<int,int>> dq;
        dq.emplace_back(0, 0);
        int dx[4] = {0, 0, 1, -1};
        int dy[4] = {1, -1, 0, 0};
        while(!dq.empty()) {
            auto [x, y] = dq.front();
            dq.pop_front();
            for(int i = 0; i < 4; i++) {
                int nx = x + dx[i];
                int ny = y + dy[i];
                if(nx < 0 || nx >= n || ny < 0 || ny >= m) continue;
                int curDist = dist[x][y] + (grid[x][y] != i + 1);
                if(dist[nx][ny] > curDist) {
                    dist[nx][ny] = curDist;
                    if(grid[x][y] == i + 1) {
                        dq.emplace_front(nx, ny);
                    }
                    else {
                        dq.emplace_back(nx, ny);
                    }
                }
            }
        }
        return dist[n - 1][m - 1];
    }
};
```

## 複雜度分析

- 時間複雜度：$O(mn)$
- 空間複雜度：$O(mn)$
