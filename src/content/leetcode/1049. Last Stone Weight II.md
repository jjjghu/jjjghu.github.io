## 思路

每次隨機挑選兩個石頭互相碰撞，最後看怎麼樣才能讓留下的那一顆最小。比如 $[2,3,5]$ ，一開始拿 5, 3 碰撞，剩下 2，再拿 2, 2 碰撞，剩下 0，這就相當於將石頭分成兩組彼此對抗。

- 組 A： $[3,2]$
- 組 B： $[5]$

如果你是先拿 3, 2 碰撞剩下 1, 再用 5, 1 碰撞剩下 4，同樣相當於分為兩組。

- 組 A： $[3]$
- 組 B： $[2,5]$

不論你怎麼碰撞，都可以劃分為兩組彼此之間的對抗，因此我們只要找到該怎麼分成兩組，並且其中一組的總和近似於 $sum/2$ （更嚴格的說， $\leq sum/2$ ）即可。

## 程式碼

### 1. 動態規劃 空間壓縮

```cpp
class Solution {
private:
    int subset(vector<int>& stones, int t) {
        vector<bool> dp(t + 1, false); // dp[j] 代表是否能合成出總合為 j 的集合
        dp[0] = true; // 沒有任何石頭可以選擇，只能組合出總和為 0 的數值
        for(int x : stones) {
            for(int j = t; j >= x; j--) {
                dp[j] = dp[j] || dp[j - x];
            }
        }
        for(int j = t; j >= 0; j--) {
            if(dp[j] == true) return j;
        }
        return -1; // impossible
    }
public:
    int lastStoneWeightII(vector<int>& stones) {
        int n = stones.size();
        int s = 0;
        for(int x : stones) s += x;
        return s - 2 * subset(stones, s / 2);
    }
};
```

### 2. 動態規劃，另一種定義

```cpp
class Solution {
private:
    int subset(vector<int>& stones, int t) {
        vector<int> dp(t + 1); // dp[j] 代表累加和不超過 j, 最大的累加和是多少
        for(int x : stones) {
            for(int j = t; j >= x; j--) {
                dp[j] = max(dp[j], dp[j - x] + x);
            }
        }
        return dp[t];
    }
public:
    int lastStoneWeightII(vector<int>& stones) {
        int n = stones.size();
        int s = 0;
        for(int x : stones) s += x;
        // groupA = subset(stones, s / 2);
        // groupB = s - groupA
        // groupB - groupA = s - 2 * subset(stones, s / 2);
        return s - 2 * subset(stones, s / 2);
    }
};
```

## 複雜度分析

> m 為所有石頭的總重量

- 時間複雜度：$O(nm)$
- 空間複雜度：空間壓縮前 $O(nm)$，空間壓縮後 $O(m)$
