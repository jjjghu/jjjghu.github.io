## 思路

定義`dfs(l1,r1,l2,r2)`代表字串`s1[l1...r1]`能否擾亂成字串`s2[l2...r2]`。\
可以發現如果一個字串若能夠擾亂成另一個字串，那麼兩個字串必然滿足以下條件：

1. 兩個字串的長度相等
2. 兩個字串中各個字元的出現次數相等。

因此能簡化`dfs`的定義，改為三個參數。`dfs(l1,l2,len)`代表字串`s1[l1...l1+len-1]`能擾亂成字串`s2[l2...l2+len-1]`。

接下來就是拆分了，我們可以在`s1[l1...l1+len-1]`中找切割點，分為左右兩段。以下簡稱`left(s1)`與`right(s1)`。只要left(s1)能擾亂成`left(s2)`，且`right(s1)`能擾亂成`right(s2)`，`s1`就能擾亂成`s2`。

枚舉所有的拆分方法，只要有任一種回傳`true`，就表示能夠擾亂成功。

---

- $ s1="abcde"\\ s2="deabc"$，選擇中間的拆分點。

- 切分後不交換：$s1=\begin{cases}
  a~bcde\\
  ab~cde\\
  abc~de\\
  abcd~e
  \end{cases}$，對應到
  $s2=\begin{cases}
  d~eabc\\
  de~abc\\
  dea~bc\\
  deab~c\\
  \end{cases}
  $
  - 切分後要交換：
    $
  s1=\begin{cases}
  a~bcde\\
  ab~cde\\
  abc~de\\
  abcd~e
  \end{cases}$
    ，對應到
    $s2=\begin{cases}
    c~deab\\
    bc~dea\\
    abc~de\\
    eabc~d\\
    \end{cases}
    $

在這些方案中，看能否讓左右兩邊都成功擾亂，比如$s1=abc~de\\s2=dea~bc$，就得看 $abc$ 能否變成 $dea$ ， $de$ 能否變成 $bc$ 。

```cpp title="暴力遞迴"
class Solution {
public:
    bool isScramble(string s1, string s2) {
        int n = s1.length();

        // dfs(l1, r1, len) 代表 s1[l1...l1 + len - 1] 是不是 s2[l2...l2 + len - 1] 的擾亂字串
        auto dfs = [&](this auto&&dfs, int l1, int l2, int len) -> bool {
            if(len == 1) {
                return s1[l1] == s2[l2];
            }
            bool res = false;
            for(int i = 1; i < len; i++) {
                res |= dfs(l1, l2, i) && dfs(l1 + i, l2 + i, len - i);
                res |= dfs(l1, l2 + len - i, i) && dfs(l1 + i, l2, len - i);
            }
            return res;
        };
        return dfs(0, 0, n);
    }
};
/*
1. 拆成左右兩半
2. 拆了之後選擇要不要交換
s1 = abcde, s2 = deabc
不交換 ab|cde vs de|abc
要交換 cde|ab vs dea|bc
*/
```

### 1. 記憶化搜索

加入記憶化搜索，並且在每一次遞迴呼叫時，都檢查一遍元素是否相同，省去計算那些不可能的切分方式。

```cpp
class Solution {
private:
    static const int MX = 30; // 起點會在 0 ~ 29
    static const int MXLEN = 31; // 長度會在 1 ~ 30
    int dp[MX][MX][MXLEN];
public:
    bool isScramble(string s1, string s2) {
        int n = s1.length();

        for(int i = 0; i < n; i++) {
            for(int j = 0; j < n; j++) {
                for(int k = 0; k <= n; k++) {
                    dp[i][j][k] = -1;
                }
            }
        }

        // dfs(l1, r1, len) 代表 s1[l1...l1 + len - 1] 是不是 s2[l2...l2 + len - 1] 的擾亂字串
        auto dfs = [&](this auto&&dfs, int l1, int l2, int len) -> bool {
            if(len == 1) {
                return s1[l1] == s2[l2];
            }

            if(dp[l1][l2][len] != -1) {
                return dp[l1][l2][len];
            }

            bool res = false;
            for(int i = 1; i < len; i++) {
                res |= dfs(l1, l2, i) && dfs(l1 + i, l2 + i, len - i);
                if(res) break;
                res |= dfs(l1, l2 + len - i, i) && dfs(l1 + i, l2, len - i);
                if(res) break;
            }
            dp[l1][l2][len] = res == true ? 1 : 0;
            return res;
        };
        return dfs(0, 0, n);
    }
};
/*
1. 拆成左右兩半
2. 拆了之後選擇要不要交換
s1 = abcde, s2 = deabc
不交換 ab|cde vs de|abc
要交換 cde|ab vs dea|bc
*/
```

### 2. 遞推

更新`dp[l1][l2][len]`時，參考的數值範圍在`dp[≥l1][≥l2][<len]`，因此更新時應該先填數值`len`較小的格子。現在空間用了三個維度，因此`l1`、`l2`的更新順序隨意，但要確保`len`是從小到大更新的。

由於更新`dp[X][X][len]`時，都會用到`dp[X][X][<len]`的格子（不止上一層），沒辦法空間壓縮。

> 注意每次更新 dp 表格子時，都需要花費 $O(n)$ 的時間。因此複雜度是 $O(n^4)$

```cpp
class Solution {
private:
    static const int MX = 30; // 起點會在 0 ~ 29
    static const int MXLEN = 31; // 長度會在 1 ~ 30
    bool dp[MX][MX][MXLEN]; // 轉成 bool, 不需要以 -1 標記未走訪了
public:
    bool isScramble(string s1, string s2) {
        int n = s1.length();

        for(int l1 = 0; l1 < n; l1++) {
            for(int l2 = 0; l2 < n; l2++) {
                dp[l1][l2][1] = s1[l1] == s2[l2];
            }
        }

        for(int len = 2; len <= n; len++) {
            // for(int l1 = n - len; l1 >= 0; l1--) { // 皆可
            for(int l1 = 0; l1 <= n - len; l1++) {
                // for(int l2 = n - len; l2 >= 0; l2--) { // 皆可
                for(int l2 = 0; l2 <= n - len; l2++) {
                    bool res = false;
                    for(int i = 1; i < len; i++) {
                        res |= dp[l1][l2][i] && dp[l1 + i][l2 + i][len - i];
                        if(res) break;
                        res |= dp[l1][l2 + len - i][i] && dp[l1 + i][l2][len - i];
                        if(res) break;
                    }
                    dp[l1][l2][len] = res;
                }
            }
        }
        return dp[0][0][n];
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n^4)$
- 空間複雜度：$O(n^3)$
