## 思路

根據題目意思，分情況討論。

1. 假如 `k=n`，唯一的子陣列就是整個陣列，此時所有數字都是「幾進缺失」的，因此在陣列中找最大值即可。
2. 假如 `k=1`，每一個子陣列大小都是 1，我們要淘汰掉那些重複出現的數字，並在只出現一次的數字當中，找最大值。

3. 在剩下的情況中，只有第一個數字跟最後一個數字，可能會被子陣列僅包含一次，因此在第一個數字跟最後一個數字中，判斷它們在整個陣列中，出現的次數是否唯一。

## 程式碼

```cpp
class Solution {
public:
    int largestInteger(vector<int>& nums, int k) {
        int n = nums.size();
        unordered_map<int, int> freq;
        for(int x : nums) freq[x]++;

        if(k == n) return ranges::max(nums);

        if(k == 1) {
            int res = -1;
            for(int x : nums) {
                if(freq[x] == 1) {
                    res = max(res, x);
                }
            }
            return res;
        }

        int a = nums[0], b = nums.back();
        if(freq[a] > 1 && freq[b] > 1) return -1;
        else if(freq[a] == 1 && freq[b] == 1) return max(a, b);
        else if(freq[a] == 1) return a;
        else return b;
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：$O(n)$
