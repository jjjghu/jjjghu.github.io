## 思路

從左上走到右下，並且走到終點的時候，自己的生命值要大於 1。\
換句話說，只要存在一條走到終點的路徑，踩過的格子數值總和 $x < health$，就回傳 `true`。\
所有路徑中，最好的那一條（`x`最小的那一條路）若不能滿足條件，那麼就不存在其他條路徑可以滿足條件了。\
因此，找出左上走到右下的最短路徑（踩到 1 就代表距離 + 1），並判斷距離跟生命值之間的關係。

## 程式碼

### 1. [Dijkstra](/dijkstra)

```cpp
class Solution {
private:
    const int dir[5] = {-1, 0, 1, 0, -1};
public:
    bool findSafeWalk(vector<vector<int>>& grid, int health) {
        using tiii = tuple<int, int, int>;
        int m = grid.size(), n = grid[0].size();

        priority_queue<tiii, vector<tiii>, greater<tiii>> pq; // grid[i][j], i, j
        pq.push(make_tuple(grid[0][0], 0, 0));

        vector<vector<bool>> visited(m, vector<bool>(n, false));
        visited[0][0] = true;

        vector<vector<int>> dist(m, vector<int>(n, INT_MAX));
        dist[0][0] = grid[0][0];

        while(!pq.empty()) {
            auto [val, x, y] = pq.top(); pq.pop();
            for(int i = 0; i < 4; i++) {
                int nx = x + dir[i];
                int ny = y + dir[i + 1];
                if(nx < 0 || nx >= m || ny < 0 || ny >= n || visited[nx][ny]) {
                    continue;
                }
                if(dist[nx][ny] > val + grid[nx][ny]) {
                    visited[nx][ny] = true;
                    dist[nx][ny] = val + grid[nx][ny];
                    pq.push(make_tuple(dist[nx][ny], nx, ny));
                }
            }
        }

        return health > dist[m - 1][n - 1];
    }
};
```

### 2. [01BFS](/01bfs)

```cpp
class Solution {
private:
    const int dir[5] = {-1, 0, 1, 0, -1};
public:
    bool findSafeWalk(vector<vector<int>>& grid, int health) {
        using pii = pair<int,int>;
        int m = grid.size(), n = grid[0].size();

        deque<pii> dq;
        dq.push_back({0, 0});

        vector<vector<int>> dist(m, vector<int>(n, INT_MAX / 2));
        dist[0][0] = grid[0][0];

        while(!dq.empty()) {
            auto [x, y] = dq.front(); dq.pop_front();
            if(x == m - 1 && y == n - 1) { // 剪枝
                return health > dist[m - 1][n - 1];
            }
            for(int i = 0; i < 4; i++) {
                int nx = x + dir[i];
                int ny = y + dir[i + 1];
                if(nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                int curDist = grid[nx][ny] + dist[x][y];
                if(dist[nx][ny] > curDist) {
                    dist[nx][ny] = curDist;
                    if(grid[nx][ny]) dq.push_back({nx, ny});
                    else dq.push_front({nx, ny});
                }
            }
        }
        return -1; // impossible
    }
};
```

## 複雜度分析

- 時間複雜度：Dijkstra $O(mn\log(mn))$，01bfs $O(mn)$
- 空間複雜度：皆為 $O(mn)$
