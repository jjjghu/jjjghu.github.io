## 思路

由於直接開大陣列會導致記憶體不足，此題用`vector`儲存數值。\
定義`dfs(i, j, remain)`代表來到位置`(i,j)`時，路徑合 `%k = remain`的路徑數。\
此時題目要的答案就相當於 `dfs(m-1, n-1, 0)`。\
想要走到位置 `(i,j)`，可以先抵達`(i-1,y)`、`(i,j-1)`，再往下、往右。不過在此之外，還有第三個條件`remain`需要滿足，這個位置的數值是`grid[i][j]`，之前路徑總和`% k`後，加上`grid[i][j]`再 `% k`要等於`remain`。\
也就是說，想計算`dp[i][j][remain]`，先要知道`dp[i][j][?]`中的問號是多少。

- `? = ((remain - grid[x][y]) % k + k) % k`，當前餘數減去格子數值，取模後加上k再取模，讓結果為正數。

### 1. 記憶化搜索

```cpp
class Solution {
private:
    const int MOD = 1e9+7;
public:
    int numberOfPaths(vector<vector<int>>& grid, int k) {
        int m = grid.size();
        int n = grid[0].size();

        vector<vector<vector<int>>> dp(m, vector<vector<int>>(n, vector<int>(k, -1)));

        // dfs(x, y, remain) = 走到 x, y 時, 路徑和 % k = remain 的路徑數目
        auto dfs = [&](this auto&&dfs, int x, int y, int remain) -> int {
            if(x == 0 && y == 0) {
                return grid[0][0] % k == remain ? 1 : 0;
            }

            int& res = dp[x][y][remain];
            if(res != -1) {
                return res;
            }

            res = 0;
            int prevRemain = ((remain - grid[x][y]) % k + k) % k;
            if(x - 1 >= 0) {
                res += dfs(x - 1, y, prevRemain);
            }
            if(y - 1 >= 0) {
                res += dfs(x, y - 1, prevRemain);
            }
            res %= MOD;
            return res;
        };

        return dfs(m - 1, n - 1, 0);
    }
};
```

### 2. 遞推

每一個格子會用到自己上方或左方格子的數值，跟二維不同的地方在於，這些格子存放的是陣列，一共有k種數值，從左上計算到右下，轉換成遞推。

```cpp
class Solution {
private:
    const int MOD = 1e9+7;
public:
    int numberOfPaths(vector<vector<int>>& grid, int k) {
        int m = grid.size();
        int n = grid[0].size();

        // dp[i][j][remain] = 走到 i-1, j-1 時, 路徑和 % k = remain 的路徑數目
        vector<vector<vector<int>>> dp(m + 1, vector<vector<int>>(n + 1, vector<int>(k, 0)));
        dp[1][1][grid[0][0] % k] = 1;

        for(int i = 1; i <= m; i++) {
            for(int j = 1; j <= n; j++) {
                for(int r = 0; r < k; r++) {
                    int prevRemain = ((r - grid[i - 1][j - 1]) % k + k) % k;
                    dp[i][j][r] += dp[i - 1][j][prevRemain];
                    dp[i][j][r] += dp[i][j - 1][prevRemain];
                    dp[i][j][r] %= MOD;
                }
            }
        }
        return dp[m][n][0];
    }
};
```

### 3. 空間壓縮

利用遞推的結果做空間壓縮，更新時可能會使用到當前格子舊有的數值，因此得用暫存紀錄下來，計算完畢後再統一更新此格的陣列內容。

```cpp
class Solution {
private:
    const int MOD = 1e9+7;
public:
    int numberOfPaths(vector<vector<int>>& grid, int k) {
        int m = grid.size();
        int n = grid[0].size();

        vector<vector<int>> dp(n + 1, vector<int>(k, 0));
        dp[1][0] = 1;
        for(int i = 1; i <= m; i++) {
            for(int j = 1; j <= n; j++) {

                vector<int> cur(k, 0);
                int val = grid[i - 1][j - 1] % k;

                for(int r = 0; r < k; r++) {
                    int prevRemain = ((r - val) % k + k) % k;
                    cur[r] = (dp[j][prevRemain] + dp[j - 1][prevRemain]) % MOD;
                }
                dp[j] = cur;
            }
        }
        return dp[n][0];
    }
};
```

## 複雜度分析

- 時間複雜度：$O(mnk)$
- 空間複雜度：空間壓縮前 $O(mnk)$，空間壓縮後 $O(nk)$
