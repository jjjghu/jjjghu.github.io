## 思路

k=2，數組 $[1,7,-5,5,3,-9,2,5]$ 中選出三個無重疊子數組，和要最大，其中選擇 $[1,7],[5,3],[2,5]$ 是最好的，因為沒有選到負數，回傳這三個子數組的起點 $[0,3,6]$ 作為答案。如果有多個結果，盡量選下標小的。

---

1. `sums`數組：`sums[i]`紀錄以`i`為起點，長度為`k`的子數組和，即`nums[i...i+k-1]`。
2. `prefix[i]`數組：`prefix[i]`紀錄`nums[0...i]`範圍上所有長度為k的子數組中，最大累加和的子數組，開頭位置在哪。

比如有個數組 $\begin{matrix} 
nums: & 3 & 2 & -5 & 3 & 7 & -2\\
i:&0 & 1 & 2 & 3 & 4 & 5 & 
\end{matrix}$，計算`prefix[2]`時，就要比對子數組 $[3,2]$ 和 $[2,-5]$ ，發現前者較大，因此`prefix[2] = 0`，因為 $[3,2]$ 的起點在位置 0。

3. `suffix[i]`數組：`suffix[i]`紀錄`nums[i...n-1]`範圍上，所有長度為`k`的子數組中，最大累加和的子數組，開頭位置在哪。（同`prefix[i]`，只是反過來）

---

得到這所有的數組後，現在要枚舉「中間的子數組」，而左右兩邊各有prefix跟suffix數組幫助計算。

## 程式碼

```cpp
class Solution {
public:
    vector<int> maxSumOfThreeSubarrays(vector<int>& nums, int k) {
        int n = nums.size();

        vector<int> sums(n);
        int curSum = 0;
        for(int i = 0; i < n; i++) { // 滑動窗口計算 sums
            curSum += nums[i];
            if(i >= k) {
                curSum -= nums[i - k];
            }
            if(i >= k - 1) {
                sums[i - k + 1] = curSum;
            }
        }

        vector<int> prefix(n, -1);
        prefix[k - 1] = 0;
        for(int i = k; i < n; i++) {
            if(sums[prefix[i - 1]] >= sums[i - k + 1]) { // 照字典序排, 如果相同, 不要動起點
                prefix[i] = prefix[i - 1];
            }
            else {
                prefix[i] = i - k + 1;
            }
        }

        vector<int> suffix(n, -1);
        suffix[n - k] = n - k;
        for(int i = n - k - 1; i >= 0; i--) {
            if(sums[suffix[i + 1]] > sums[i]) { // 照字典序排, 如果相同, 讓起點變少
                suffix[i] = suffix[i + 1];
            }
            else {
                suffix[i] = i;
            }
        }

        int left = -1, mid = -1, right = -1;
        int res = INT_MIN;
        for(int i = k; i <= n - 2 * k; i++) { // 枚舉中間子數組的起點
            // 當前參考答案 = nums[0...i] 中選擇最好的子數組 +
            //               nums[i...k] 這個子數組 +
            //               nums[i+k...n-1]最好的子數組
            int cur = sums[prefix[i - 1]] + sums[i] + sums[suffix[i + k]];
            if(cur > res) {
                res = cur;
                left = prefix[i - 1];
                mid = i;
                right = suffix[i + k];
            }
        }
        return {left, mid, right};
    }
};
/*
n = 8, k = 2
nums[i]   = 1  2  1  2  6  7  5  1
sums[i]   = 3  3  3  8 13 12  6  0
prefix[i] = -  0  0  0  3  4  4  4
suffix[i] = 4  4  4  4  4  5  6  -
idxs      = 0  1  2  3  4  5  6  7

*/
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：$O(n)$
