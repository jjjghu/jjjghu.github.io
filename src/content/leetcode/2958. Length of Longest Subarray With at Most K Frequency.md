## 思路

對於固定的右邊界，需要找到盡量靠左的左邊界，來找到滿足條件的最長子數組。\
用一個哈希表`freq`記錄每個數字在當前兩邊界中的數量，當新的右邊界導致字元出現數量$\geq k$ 時。\
移動左指針，直到重新讓這個多出來的字元被降低到 $==k$ 的情況。

## 程式碼

```cpp title="滑動窗口"
class Solution {
public:
    int maxSubarrayLength(vector<int>& nums, int k) {
        int n = nums.size();
        unordered_map<int, int> freq;
        int res = 0;
        int left = 0;
        for(int right = 0; right < n; right++) {
            freq[nums[right]]++;
            while(freq[nums[right]] > k) {
                freq[nums[left++]]--;
            }
            res = max(res, right - left + 1);
        }
        return res;
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：$O(n)$
