## 思路

定義`dfs(i, j)`代表以`matrix[i][j]`為終點的最長遞增路徑長。\
因為題目要求嚴格遞增，所以不會有在原地打轉，導致路徑無限長的情況，因此也不會有狀態相互依賴的關係。\
這是自頂而下的方法，既然以自己為終點，那麼可能的來處就是自己的周圍格子。而要從周圍格子來到自己這個位置，就須滿足`matrix[i][j] > matrix[ni][nj]`。\
算出所有的`dfs(i,j)`，取最大值即為所求。

> 此題的依賴關係不太好整理，自然也就沒有了空間壓縮的版本，到此就停了。\
> 之後的問題就直接從定義開始了，而不從遞迴慢慢入手。

```cpp title="記憶化搜索"
class Solution {
private:
    static const int MX = 201;
    int dp[MX][MX];
    const int dir[5] = {-1, 0, 1, 0, -1};
public:
    int longestIncreasingPath(vector<vector<int>>& matrix) {
        int m = matrix.size();
        int n = matrix[0].size();
        for(int i = 0; i < m; i++) {
            fill(dp[i], dp[i] + n + 1, -1);
        }

        // dfs(i, j) = 以 matrix[i][j] 為終點的最長遞增路徑的長度
        auto dfs = [&](this auto&&dfs, int i, int j) -> int {
            int& res = dp[i][j];
            if(res != -1) {
                return res;
            }
            res = 1;
            for(int k = 0; k < 4; k++) {
                int ni = i + dir[k];
                int nj = j + dir[k + 1];
                // 沒有越界，且鄰居要比自己小，才能從鄰居來到自己的位置
                if(ni < 0 || ni >= m || nj < 0 || nj >= n || matrix[ni][nj] >= matrix[i][j]) continue;
                res = max(res, dfs(ni, nj) + 1);
            }
            return res;
        };

        int res = 1;
        for(int i = 0; i < m; i++) {
            for(int j = 0; j < n; j++) {
                res = max(res, dfs(i, j));
            }
        }
        return res;
    }
};
```

## 複雜度分析

- 時間複雜度：$O(mn)$
- 空間複雜度：$O(mn)$
