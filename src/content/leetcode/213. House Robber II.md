## 思路

在[[198]]之上多加了環形的條件，需要額外避免首尾都偷的問題。
只需要討論第一間房屋偷不偷的問題，就能將問題簡化為非環形的狀態。

- 偷第一間：`nums[0]` + 偷 `nums[2...n-1]`
- 不偷第一間：偷`nums[1...n-1]`。

```cpp　title="打家劫舍 II"
class Solution {
private:
    int helper(vector<int>& nums, int left, int right) { // 左閉右閉
        int skip = 0;
        int steal = nums[left];
        for(int i = left + 1; i <= right; i++) {
            int oldSkip = skip;
            skip = max(skip, steal); // skip 會被更新, 因此要先暫存
            steal = nums[i] + oldSkip;
        }
        return max(skip, steal);
    }
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        if(n == 1) {
            return nums[0];
        }
        if(n == 2) {
            return max(nums[0], nums[1]);
        }
        // 首尾相連
        // 不偷 nums[0], 偷 nums[1...n-1]
        // 要偷 nums[0], 偷 nums[2...n-2]
        return max(helper(nums, 1, n - 1), helper(nums, 2, n - 2));
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：$O(1)$
