## 思路

### 暴力遞迴

現在給你一個陣列`days`，這些是你要去旅行的天數。旅行時，你有三種票可以買，一日票、週票、月票可以買。各自有不同的價格，票價記錄在`costs`中。你有許多方案可以選擇，比如全都使用日票或都使用月票，需要找出哪一種方案花費最低。
假設現在`days` = $[3,4,9,20,50,\cdots]$ ，`days[0]`代表第一個要去旅遊的時間在第三天，此時，你有三個選項。

- 買日票：遊玩 $[3]$ 這一天，花費`cost[0]`。
- 買週票：遊玩 $[3,4,9]$ 這三天，\
  因為這張票能在3,4,5,6,7,8,9這幾天用，花費`cost[1]`。
- 買月票：遊玩 $[3,4,9,20]$ 這四天，花費`cost[2]`。

---

$$
days = [3,4,9,20,50,\cdots]
$$

定義遞迴函數`dfs(i)`，代表從下標i開始，一直到最後一天所需要的最低消費。題目需要的答案，就是`dfs(0)`，這代表從`days[0]`開始，旅遊到最後一天的最低花費。

- 終止條件：假如現在下標已經是`days.size()`，現在已經越界了，最低花費自然就是 0 。
- 遞迴呼叫：比如現在來到`days[2]`。
  - 買日票，花費cost[0]，遞迴呼叫`dfs(3)`
  - 買週票，花費cost[1]，遞迴呼叫`dfs(3)`
  - 買月票，花費cost[2]，遞迴呼叫<span style="color:var(--color-accent-fg)">`dfs(4)`</span>（因為`days[3]`可以用這張票）
- 綜合以上，對於`dfs(2)`來說，他的參考答案有三，要在其中選擇最小的作為答案。
  - `cost[0] + dfs(3)`
  - `cost[1] + dfs(3)`
  - `cost[2] + dfs(4)`
    三種方案，每一種方案都需要知道下一層遞迴呼叫時，應該要選擇哪一個下標。這個下標`j`，是「第一個日票/周票/月票無法使用的那天」所對應的下標。

```cpp title="最低票價 記憶化搜索 暴力遞迴"
class Solution {
private:
    static constexpr int durations[3] = {1, 7, 30};
public:
    int mincostTickets(vector<int>& days, vector<int>& costs) {
        int n = days.size();

        // dfs(0) 代表從第 days[0] 開始，一直到最後一天，所需要的最低消費。
        auto dfs = [&](this auto&&dfs, int i) -> int {
            if(i == n) { // 越界，最低消費為 0
                return 0;
            }

            // j = 現在在下標 i, days[i] 在加上天數後，第一個沒有被包含的天數下標
            int res = INT_MAX;
            int j = i + 1;
            for(int k = 0; k < 3; k++) {
                while(j < n && days[i] + durations[k] - 1 >= days[j]) {
                    j++;
                }
                // 現在 days[i] + durations[k] < days[j], 或是越界
                res = min(res, costs[k] + dfs(j));
            }
            return res;
        };

        return dfs(0);
    }
};
```

### 記憶化搜索

在前面的暴力遞迴的舉例當中，可以注意到`dfs(3)`被呼叫了兩次。但是現在兩次呼叫，都會真的去計算一次，花費掉額外的時間。因此，我們可以建立一個暫存的空間，把計算過的資料都放到裡面，就能節省下大量重複計算的時間。

```cpp title="最低票價 記憶化搜索"
class Solution {
private:
    static constexpr int MX = 365 + 1;
    static constexpr int durations[3] = {1, 7, 30};
    int dp[MX];
public:
    int mincostTickets(vector<int>& days, vector<int>& costs) {
        int n = days.size();
        fill(dp, dp + n + 1, INT_MAX);

        // dfs(0) 代表從第 days[0] 開始，一直到最後一天，所需要的最低消費。
        auto dfs = [&](this auto&&dfs, int i) -> int {
            if(i == n) { // 越界，最低消費為 0
                return 0;
            }

            int& res = dp[i]; // 注意這裡是引用
            if(res != INT_MAX) { // 已經計算過，不需要重複計算
                return res;
            }

            // j = 現在在下標 i, days[i] 在加上天數後，第一個沒有被包含的天數下標
            int j = i + 1;
            for(int k = 0; k < 3; k++) {
                while(j < n && days[i] + durations[k] - 1 >= days[j]) {
                    j++;
                }
                // 現在 days[i] + durations[k] < days[j], 或是越界
                res = min(res, costs[k] + dfs(j));
            }
            return res;
        };

        return dfs(0);
    }
};
```

### 遞推

想要把自頂向下的方法改成自底向上，先要釐清數值間的依賴關係。

在前面的例子中，想要知道`dfs(0)`的數值，要先算出`dfs(i), i>0`的數值，因此，「比較簡單的子問題」，是參數比較大的遞迴呼叫，所以倒序計算`dp`表，其餘方法都與前面相同。

```cpp title="最低票價 遞推"
class Solution {
private:
    static constexpr int MX = 365 + 1;
    static constexpr int durations[3] = {1, 7, 30};
    int dp[MX];
public:
    int mincostTickets(vector<int>& days, vector<int>& costs) {
        int n = days.size();
        fill(dp, dp + n + 1, INT_MAX);

        // dp[i] 代表從第 days[0] 開始，一直到最後一天，所需要的最低消費。
        dp[n] = 0; // 越界，最低消費為 0
        for(int i = n - 1; i >= 0; i--) {
            // j = 現在在下標 i, days[i] 在加上天數後，第一個沒有被包含的天數下標
            int j = i + 1;
            for(int k = 0; k < 3; k++) {
                while(j < n && days[i] + durations[k] - 1 >= days[j]) {
                    j++;
                }
                // 現在 days[i] + durations[k] < days[j], 或是 j 越界 (j == n)
                dp[i] = min(dp[i], costs[k] + dp[j]);
            }
        }
        return dp[0];
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：空間壓縮前 $O(n)$, 壓縮後 $O(1)$
