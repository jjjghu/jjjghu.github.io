## 思路

定義 $dp[i]$ 代表 $s[0]\sim s[i]$ 的不同子序列個數。
字串 $abab$ 中，分別對應到子序列如下所示。

1.  $a:\{\}, \{a\}$
2.  $b：\gray{\{\}, \{a\}}, \{b\}, \{ab\}$ ，就是拿上次的內容，接上 $b$ 得到下一層。
3.  $a:\gray{\{\}, \{a\}, \{b\}, \{ab\}}, \{a\}, \{aa\}, \{ba\}, \{aba\}$ ，接上 $a$ 得到下一層。

- $\{a\}$ 有重複，應該去掉。

4. $b:\begin{aligned}
   \{\},& \{a\},& \{b\},& \{ab\},& \{aa\},& \{ba\},& \{aba\}\\
   \{b\},& \{ab\},& \{bb\},& \{abb\},& \{aab\},& \{bab\},& \{abab\}\\
   \end{aligned}$，下排是此次新增的子序列

- 重複的有 $\{b\}, \{ab\}$ 兩個。

---

在上面的過程中，我們知道 $dp[i]=dp[i-1]\times2-\small{重複的子序列數量}$ 。

- 第一個 $dp[i-1]$ ：代表 $s[0]\sim s[i-1]$ 的不同子序列個數。
- 第二個 $dp[i-1]$ ：代表 $s[0]\sim s[i-1]$ 的不同子序列，都接上 $s[i]$ 後的個數。
- 重複的子序列數量：這次加入的字元是 $s[i]$ ，那麼會重複的子序列也一定是以 $s[i]$ 為結尾的序列。
  > 這次加入的字元是 b, 那麼重複的子序列也一定是以 b 結尾。
  - 觀察上面例子中的兩次重複， $dp[3]$ 計算時，重複的 $b, ab$ 是在 $dp[2]$ 加入的，但這不代表要扣除 $dp[i-2]$ ，而是扣除 $dp[i-3]$ ，至於為什麼，可以自己拿`aaa`推論看看。

```cpp title="不同的子序列II 動態規劃 好理解寫法"
class Solution {
private:
    static const int MX = 2001;
    static const int MOD = 1e9+7;
    int dp[MX];
public:
    int distinctSubseqII(string s) {
        int n = s.length();

        fill(dp, dp + n + 1, 0);
        dp[0] = 1;

        int lastPos[26];
        fill(lastPos, lastPos + 26, -1);

        for(int i = 1; i <= n; i++) { // 注意這裡跟下方範例差一, dp[i] 代表 s[0] ~ s[i - 1]
            int pos = lastPos[s[i - 1] - 'a'];
            dp[i] = (2LL * dp[i - 1]) % MOD;
            if(pos - 1 >= 0) { // 上次出現的位置 - 1
                dp[i] = (1LL * dp[i] - dp[pos - 1] + MOD) % MOD;
            }
            lastPos[s[i - 1] - 'a'] = i;
        }
        dp[n] = (dp[n] - 1 + MOD) % MOD;
        return dp[n]; // 減去空集合
    }
};
/*
dp[i] = s[0] ~ s[i] 的不同非空子序列個數

abc, 最初只有 {}一個空序列
a: {}, {a}
b: {}, {a}, {b}, {ab} (用 dp[i - 1] 的結果接上 b)
c: {}, {a}, {b}, {ab}, {c}, {ac}, {bc}, {abc} (用 dp[i - 1] 的結果接上 c)
-----------------------------------
abab, 最初只有 {}, 一個空序列
a: {}, {a}
b: {}, {a}, {b}, {ab}

a: {}, {a}, {b}, {ab},
   {a}, {aa}, {ba}, {aba}, 其中 a 重複了, 要將可能性減去 dp[0] 新增的數量

b: {}, {a}, {b}, {ab}, {aa}, {ba}, {aba},
   {b}, {ab}, {bb}, {abb}, {aab}, {bab}, {abab},  其中 b, ab 重複, 將可能性減去 dp[1] 新增的數量

dp[i] = 2, 4, 7, 12
dp[i] = dp[i - 1] * 2 - dp[這個字元上次出現的位置pos] + dp[pos - 1]
-----------------------------------
aaa, 最初只有 {}, 一個空序列
a: {}, {a}
a: {}, {a}, {a}, {aa}, 重複 a, 可能性減去 dp[0] 新增的數量
a: {}, {a}, {aa},
   {a}, {aa}, {aaa}, 重複 a, aa, 可能性減去 dp[1] 新增的數量
dp[i] = 2, 3, 5 - dp[pos - 1]
*/
```

```cpp title="不同的子序列II 動態規劃 簡化寫法"
class Solution {
private:
    static const int MX = 2001;
    static const int MOD = 1e9+7;
    int dp[MX];
public:
    int distinctSubseqII(string s) {
        int n = s.length();

        fill(dp, dp + n + 1, 0);
        dp[0] = 1; // 越界，至少有一個空集合

        int last[26]{}; // 紀錄上次字元擴充時的數量

        for(int i = 1; i <= n; i++) { // 注意這裡跟下方範例差一, dp[i] 代表 s[0] ~ s[i - 1]
            int val = last[s[i - 1] - 'a'];
            last[s[i - 1] - 'a'] = dp[i - 1];
            dp[i] = (2LL * dp[i - 1] - val + MOD) % MOD;
        }
        dp[n] = (dp[n] - 1 + MOD) % MOD; // 減去空集合
        return dp[n];
    }
};
```

在更新 $dp[i]$ 時，只會用到 $dp[i-1]$ 與last陣列中紀錄的數值，因此能用一個變數代替 $dp[i-1]$ ，節省 $O(n)$ 的空間消耗。

```cpp title="不同的子序列 II 動態規劃 空間優化"
class Solution {
private:
    static const int MOD = 1e9+7;
public:
    int distinctSubseqII(string s) {
        int n = s.length();

        int all = 1; // 用來代替 dp[i - 1], 最初是 dp[0] = 1;
        int last[26]{}; // 原先紀錄的是上次字元出現的位置, 現在直接紀錄對應的數值
        for(char c : s) { // 不再差一
            // 跟註解寫法是一樣的
            int newAdd = (all - last[c - 'a'] + MOD) % MOD;
            all = (all + newAdd) % MOD;
            last[c - 'a'] = (last[c - 'a'] + newAdd) % MOD;
            // int val = last[c - 'a'];
            // last[c - 'a'] = all;
            // all = (2LL * all - val + MOD) % MOD;
        }
        return (all - 1 + MOD) % MOD; // 減去空集合
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：空間壓縮前 $O(n)$, 壓縮後 $O(1)$
