## 思路
先不考慮送的東西，這個問題就變成了完全背包的問題。在題單當中有相關題目，可以先去練習一番。

定義`dp[i][j]`代表在前 `i` 個商品當中選擇，容量限制在 `j` 以下，可以容納的最多商品數量。\
更新`dp[i][j]`時，有兩個選項：
- 選擇要拿物品 $i$ ：$dp[\blue{i}][j-cost] + 1$，多拿到了一個物品。
- 選擇不拿物品 $i$ ：$dp[i-1][j]$，
但是，這樣我們沒有考慮進免費送的那些商品。

免費送的商品有幾個，取決於輸入的`factor`，需要用它來得知，當我買商品 $i$ 時，有多少商品會免費送給我。\
這個贈送最多只會送一次，我第一次買這個商品時才會送。\
那麼，更新 $dp[i][j]$ 時，我要怎麼判斷，這是不是第一次買這個商品呢？

$dp[i - 1][j - cost]$ 代表在前 $\blue{i-1}$ 個商品中，容量在 $j-cost$ 以下，可以容納的最多商品數量。
在這種情況下，購買商品`i`，就代表是第一次買這個商品，我可以拿到贈品，而贈品的數量，可以預先處理好。

## 程式碼
### 完全背包
```cpp
class Solution {
private:
    int compute1(vector<vector<int>>& items, int budget) {
        int n = items.size();

        vector<int> free(n, 1); // free 是贈品加上購買的商品本身，所以用 1
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (items[i][0] % items[j][0] == 0) {
                    free[j]++;
                }
                if (items[j][0] % items[i][0] == 0) {
                    free[i]++;
                }
            }
        }

        // 如果不在乎會送東西的話，要怎麼算？在限制下選擇商品？完全背包
        // dp[i][j] 代表在前 i 個商品下，容量限制在 j 以下可以容納的最多商品數量
        vector<vector<int>> dp(n + 1, vector<int>(budget + 1, 0));
        for (int i = 1; i <= n; i++) {
            int cost = items[i - 1][1];
            for (int j = 0; j <= budget; j++) {
                // 不去選商品 i: dp[i - 1][j]
                // 多選一個商品 i: dp[i][j - cost] + 1
                // 多選一個商品 i，第一次買: dp[i - 1][j - cost] + free[i]
                if (j - cost >= 0) {
                    dp[i][j] = max({dp[i - 1][j], dp[i][j - cost] + 1, dp[i - 1][j - cost] + free[i - 1]});
                }
                else {
                    dp[i][j] = dp[i - 1][j];
                }
            }
        }

        return dp[n][budget];
    }

    // 空間壓縮版本
    int compute2(vector<vector<int>>& items, int budget) {
        int n = items.size();

        vector<int> free(n, 1);
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (items[i][0] % items[j][0] == 0) {
                    free[j]++;
                }
                if (items[j][0] % items[i][0] == 0) {
                    free[i]++;
                }
            }
        }

        vector<int> dp(budget + 1, 0);
        vector<int> lastDP = dp;
        for (int i = 0; i < n; i++) {
            int cost = items[i][1];
            for (int j = cost; j <= budget; j++) {
                dp[j] = max({lastDP[j], dp[j - cost] + 1, lastDP[j - cost] + free[i]});
            }
            lastDP = dp;
        }
        return dp[budget];
    }

public:
    int maximumSaleItems(vector<vector<int>>& items, int budget) {
        return compute2(items, budget);
    }
};
```
## 複雜度分析
- 時間複雜度：$O(n^2 + nm)$
- 空間複雜度：空間壓縮前 $O(nm)$，空間壓縮後 $O(m)$
