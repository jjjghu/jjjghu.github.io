## 思路

> 在想題目時實際上會有很多迂迴的思考過程，我盡量將它記錄在註解，最終還是要靠自己去想。

定義 $dp[i]$ 代表以 $s[i]$ 為結尾的不同非空子字串數量。下面舉兩個例子。

1. `zabx`
   - `z: 1 (z)`
   - `a: 2 (a, za)`
   - `b: 3 (b, ab, zab)`
   - `x: 1 (x)`

---

2. `zabzabc`
   - `z: 1 (z)`
   - `a: 2 (a, za)`
   - `b: 3 (b, ab, zab)`
   - `z: 1 (z) (重複)`
   - `a: 2 (a, za) (重複)`
   - `b: 3 (b, ab, zab) (重複)`
   - `c: 4 (c, bc, abc, zabc)`

---

從上面兩個例子中，我們可以得出以下結論：

1. 單一字元一定可以是字字串
2. 可能會算到重複的子字串，需要去重。
   - 取長度最大即可，如果有比如`zabab`的形式，只需要取`zab`對應的答案，而不需要後方`ab`的重複結果。
3. 計算 $dp[i]$ 時，如果可以連上上一個字元，就表示自己可以加上它的數值。

## 程式碼

### 1. 動態規劃

```cpp
class Solution {
private:
    static const int MX = 1e5+1;
    int dp[MX];
public:
    int findSubstringInWraproundString(string s) {
        int n = s.length();
        fill(dp, dp + n, 1);

        int res[26]{}; // 每個字元曾經得到的最佳答案
        res[s[0] - 'a'] = 1;
        for(int i = 1; i < n; i++) {
            if((s[i - 1] == 'z' && s[i] == 'a') || s[i] - s[i - 1] == 1) {
                dp[i] += dp[i - 1];
            }
            int idx = s[i] - 'a';
            res[idx] = max(res[idx], dp[i]);
        }

        return reduce(res, res + 26);
    }
};
/*
dp[i] = 以 s[i] 為結尾的不同的非空子字串數量 = 以 s[i] 為結尾的最長連續子字串

zabx
z: 1 (z)
a: 2 (a, za)
b: 3 (b, ab, zab)
x: 1 (x)

zabzabc
z: 1 (z)
a: 2 (a, za)
b: 3 (b, ab, zab)

z: 1 (z) (重複)
a: 2 (a, za) (重複)
b: 3 (b, ab, zab) (重複)
c: 4 (c, bc, abc, zabc)

*/
```

注意到每次計算 $dp[i]$ 時，都只會用到 $dp[i-1]$ 紀錄的資訊，因此能用一個單一變數代表 $dp[i-1]$ ，省去 $O(n)$ 空間。

### 2. 空間壓縮

```cpp
class Solution {
public:
    int findSubstringInWraproundString(string s) {
        int n = s.length();

        int res[26]{}; // 每個字元曾經得到的最佳答案
        res[s[0] - 'a'] = 1;
        int len = 1;
        for(int i = 1; i < n; i++) {
            if((s[i - 1] == 'z' && s[i] == 'a') || s[i] - s[i - 1] == 1) {
                len++;
            }
            else {
                len = 1;
            }
            int idx = s[i] - 'a';
            res[idx] = max(res[idx], len);
        }

        return reduce(res, res + 26);
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：空間壓縮前 $O(n)$，壓縮後$O(1)$
