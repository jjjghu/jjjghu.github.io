## 思路

定義 `dfs(i)` 代表當前玩家從 `stoneValue[i]` 開始選，最多能拿到幾分。\
那麼對於這個玩家來說，在位置 `i` 時，此時他有三種選擇，而對方也會以自己的最佳策略去選擇要拿幾堆

1. 拿走一堆石子，將剩下的局面交給對方，對應`dfs(i+1)`。
2. 拿走兩堆石子，將剩下的局面交給對方，對應`dfs(i+2)`。
3. 拿走三堆石子，將剩下的局面交給對方，對應`dfs(i+3)`。

假如現在我選擇拿走一堆石子（也就是取走 `stoneValue[i]`）。
對方在衍生的局面中，一共 `sum(stoneValue[i+1...n-1])` 分中，他能拿到 `dfs(i+1)` 分，\
也就是說，我除了取走的這一堆石子外，還可以獲得 `sum(stoneValue[i+1...n-1] - dfs(i + 1)`分。

在三種選擇中，選擇對自己最好的一種策略，並加入記憶化搜索避免重複計算。

## 程式碼

### 1.記憶化搜索

```cpp
class Solution {
private:
    static const int MX = 5e4+1;
    int dp[MX];
public:
    string stoneGameIII(vector<int>& stoneValue) {
        int n = stoneValue.size();

        vector<int> suffix(n + 1, 0);
        suffix[n - 1] = stoneValue[n - 1];
        for(int i = n - 2; i >= 0; i--) {
            suffix[i] = suffix[i + 1] + stoneValue[i];
        }

        for(int i = n - 1; i >= 0; i--) {
            int score = INT_MIN;
            int take = stoneValue[i];
            score = max(score, take + suffix[i + 1] - dp[i + 1]);
            if(i + 1 < n) {
                take += stoneValue[i + 1];
                score = max(score, take + suffix[i + 2] - dp[i + 2]);
            }
            if(i + 2 < n) {
                take += stoneValue[i + 2];
                score = max(score, take + suffix[i + 3] - dp[i + 3]);
            }
            dp[i] = score;
        }

        int aliceScore = dp[0];
        int bobScore = suffix[0] - aliceScore;
        if(aliceScore > bobScore) return "Alice";
        else if(aliceScore < bobScore) return "Bob";
        else return "Tie";
    }
};
```
