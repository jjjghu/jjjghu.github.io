## 思路

> 前置題目 [[300]]

題目相當於信封的長跟寬都需要嚴格遞增，問最多能連續多少個信封。相當於二維的最長遞增子序列問題。

---

定義`dp[i]`代表以`envelops[i]`為結尾，最多能連續套幾封信。

$$
dp[i]=\begin{cases}
max(dp[j] + 1) & \forall~j<i~\text{and}~e[j][0]<e[i][0]~\text{and}~e[j][1]<e[i][1]\\
1 & \text{otherwise}
\end{cases}
$$

> e 是 envelops 的簡稱。

```cpp title="動態規劃 TLE"
class Solution {
private:
    static const int MX = 1e5+1; // O(n^2) = 1e10, TLE
    int dp[MX];
public:
    int maxEnvelopes(vector<vector<int>>& envelopes) {
        ranges::sort(envelopes, [&](vector<int>& a, vector<int>& b) {
            return a[0] == b[0] ? a[1] < b[1] : a[0] < b[0];
        });

        int n = envelopes.size();
        int res = 1;
        for(int i = 0; i < n; i++) {
            dp[i] = 1;
            for(int j = 0; j < i; j++) {
                if(envelopes[j][0] < envelopes[i][0] &&
                   envelopes[j][1] < envelopes[i][1]) {
                    dp[i] = max(dp[i], dp[j] + 1);
                }
            }
            res = max(res, dp[i]);
        }
        return res;
    }
};
```

排序數組時，你把寬度由小排到大，但在同寬度的情況下，高度由大到小排。\
這時，你只需要在乎信封的高度，在從排序好的數組當中，找最長遞增子序列就行了。\
排序後，對於一個信封來說，它左邊的信封寬度只會 $\leq$ 自己，會有寬度相同，但卻錯誤套上的情況嗎？不會有這種情況，因為如果寬度相同，排序後，它的高度必須要 $\geq$ 自己，才會排到自己的前面去。\
遇到最極端的情況，就是長寬都相同，而我們求的是最長遞增子序列，所以不會算錯。

## 程式碼

### 動態規劃 + 二分搜

```cpp
class Solution {
private:
    static const int MX = 1e5+1;
    // int dp[MX]; // dp[i] 代表以 envelops[i] 為結尾，最多能連續套幾封信。
    int ends[MX]; // 定義 ends[i] 代表一共套 i+1 層時，目前高度的最小結尾

    int findPos(int h, int endSize) { // 在 ends 中, 找到第一個 >= h 的位置
        int pos = -1; // 沒有找到可行位置
        int left = 0, right = endSize - 1;
        while(left <= right) {
            int mid = left + (right - left) / 2;
            if(ends[mid] >= h) {
                pos = mid;
                right = mid - 1;
            }
            else {
                left = mid + 1;
            }
        }
        return pos;
    }
public:
    int maxEnvelopes(vector<vector<int>>& envelopes) {
        ranges::sort(envelopes, [&](vector<int>& a, vector<int>& b) {
            return a[0] == b[0] ? a[1] > b[1] : a[0] < b[0]; // 寬度遞增, 高度要遞減
        });

        int n = envelopes.size();
        int endSize = 0;
        for(int i = 0; i < n; i++) {
            int pos = findPos(envelopes[i][1], endSize);
            if(pos == -1) {
                ends[endSize++] = envelopes[i][1];
                // dp[i] = endSize;
            }
            else {
                ends[pos] = envelopes[i][1];
                // dp[i] = pos + 1; // 最後不會用到 dp 陣列
            }
        }
        return endSize;
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n\log{n})$
- 空間複雜度：$O(n)$
