## 思路

動態規劃中，遞迴中的參數往往都比較簡單，一般不會比`int`更複雜。\
此題無法用動態規劃，因為它是「帶有路徑的」（參數複雜），不適合或者說沒有必要改成動態規劃。假如你硬改，那麼一個狀態的儲存，會花費很多額外空間。

> 除了`i,j,k`以外，你還要將`board`一同作為參數儲存。
> 這也代表相同的子問題，被重複使用的機率也不高，動態規劃所能帶來的好處不明顯。

## 程式碼

```cpp title="單字搜索 遞迴"
class Solution {
public:
    bool exist(vector<vector<char>>& board, string word) {
        int m = board.size();
        int n = board[0].size();

        auto dfs = [&](this auto&&dfs, int i, int j, int k) -> bool {
            if(k == word.length()) { // 長度相等，找到答案
                return true;
            }

            // 越界，或字元沒對上
            if(i < 0 || i >= m || j < 0 || j >= n || board[i][j] != word[k]) {
                return false;
            }

            char temp = board[i][j];
            board[i][j] = '*'; // 標記為已走訪
            bool res = dfs(i - 1, j, k + 1) ||
                       dfs(i + 1, j, k + 1) ||
                       dfs(i, j - 1, k + 1) ||
                       dfs(i, j + 1, k + 1);
            board[i][j] = temp;
            return res;
        };

        for(int i = 0; i < m; i++) {
            for(int j = 0; j < n; j++) {
                if(dfs(i, j, 0)) {
                    return true;
                }
            }
        }
        return false;
    }
};
```

## 複雜度分析

> M, N 代表矩陣長寬, K 代表單字長度

- 時間複雜度：$O(MN3^K)$
- 空間複雜度：系統調用的棧空間 $O(K)$
