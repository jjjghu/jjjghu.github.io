## 思路

方法跟[[1631]]差不多，因為每一個節點的鄰居都是固定的，\
因此實際上不需要一張圖記錄鄰居，而是能直接開始 Dijkstra。

## 程式碼

### Dijkstra

```cpp
class Solution {
private:
    static constexpr int MX_N = 50;
    static constexpr int dir[5] = {-1, 0, 1, 0, -1};
    int dist[MX_N][MX_N];
public:
    int swimInWater(vector<vector<int>>& grid) {
        int n = grid.size();
        for(int i = 0; i < n; i++) {
            fill(dist[i], dist[i] + n, INT_MAX);
        }
        using tiii = tuple<int,int,int>;
        priority_queue<tiii, vector<tiii>, greater<tiii>> pq; // dist, x, y
        pq.emplace(grid[0][0], 0, 0);
        dist[0][0] = grid[0][0];
        while(!pq.empty()) {
            auto [curDist, x, y] = pq.top(); pq.pop();
            if(curDist > dist[x][y]) continue;
            if(x == n - 1 && y == n - 1) {
                return curDist;
            }
            for(int i = 0; i < 4; i++) {
                int nx = x + dir[i], ny = y + dir[i + 1];
                if(nx < 0 || nx >= n || ny < 0 || ny >= n) continue;
                int newDist = max(curDist, grid[nx][ny]);
                if(newDist < dist[nx][ny]) {
                    dist[nx][ny] = newDist;
                    pq.emplace(newDist, nx, ny);
                }
            }
        }
        return -1; // impossible
    }
};
```

## 複雜度分析

- 時間複雜度：$O(mn\log(mn))$
- 空間複雜度：$O(mn)$
