## 思路

1. 先利用`bfs`找到哪些節點是可疑方法並標註。
2. 再檢查所有邊中，有沒有「非可疑方法」呼叫「可疑方法」，如果有，就表示存在可疑方法不能被移除。
3. 假如有可疑方法不能被移除，回傳所有方法。否則把所有可疑方法移除並回傳。

## 程式碼

### bfs

```cpp
class Solution {
public:
    vector<int> remainingMethods(int n, int k, vector<vector<int>>& invocations) {
        vector<vector<int>> graph(n);
        for(auto& edge : invocations) {
            graph[edge[0]].push_back(edge[1]);
        }

        vector<bool> isSusMethod(n, false); // 同時充當 visited 陣列
        isSusMethod[k] = true;
        queue<int> q;
        q.push(k);
        while(!q.empty()) {
            int u = q.front(); q.pop();
            for(int v : graph[u]) {
                if(isSusMethod[v]) continue;
                isSusMethod[v] = true;
                q.push(v);
            }
        }
        bool canRemove = true;
        for(auto& edge : invocations) {
            int u = edge[0], v = edge[1];
            if(isSusMethod[v] && !isSusMethod[u]) {
                canRemove = false;
                break;
            }
        }

        vector<int> res;
        if(!canRemove) {
            res.resize(n);
            ranges::iota(res, 0);
        }
        else {
            for(int i = 0; i < n; i++) {
                if(!isSusMethod[i]) {
                    res.push_back(i);
                }
            }
        }
        return res;
    }
};
```

## 複雜度分析

> m 代表邊的數量

- 時間複雜度：$O(n)$
- 空間複雜度：$O(n+m)$
