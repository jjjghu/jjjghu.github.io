## 思路

假如陣列中全是偶數或奇數，直接複製數組即可。接下來討論陣列中奇偶兩種皆有的情況。

1. 方案一: 建立偶數數組，需要處理所有的奇數。\
   把所有的奇數都減去最小的奇數，變成偶數。\
   最小的奇數怎麼變成偶數？方案一不可能。
2. 方案二: 建立奇數數組，需要處理所有的偶數。\
   把所有的偶數減去最小的奇數，變成奇數。\
   前提條件: 最小的偶數要比最小的奇數大，否則方案二不可能。

## 程式碼

```cpp
class Solution {
public:
    bool uniformArray(vector<int>& nums) {
        int minOdd = INT_MAX, minEven = INT_MAX;
        for(int x : nums) {
            if(x & 1) {
                minOdd = min(minOdd, x);
            }
            else {
                minEven = min(minEven, x);
            }
        }
        if(minOdd == INT_MAX || minEven == INT_MAX) { // 等於 INT_MAX, 代表不存在偶數或奇數
            return true; // 直接複製即可
        } else {
            if(minEven > minOdd) {
                return true;
            } else {
                return false;
            }
        }
    }
};
```

## 複雜度分析

- 時間複雜度：$O(n)$
- 空間複雜度：$O(1)$
